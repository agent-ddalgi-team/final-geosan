# 접촉 준비(가설) — 10/29 시연용 공통 1장

> **시연용 초안·거산 확인 전** · PM 작성 2026-10-24 · 이슈 #26
>
> **거산이 공정(아연도금·아노다이징)과 거래 관계를 확인해 주면 이렇게 접근한다는 "제안"입니다. 영업은 거산이 훨씬 잘 아시니, 맞는지·무엇을 더 넣어야 할지 의견 부탁드립니다**(방문 질문 D4).
>
> 회사별 1쪽 메모(`demo/memos/`)의 "6. 접촉 준비"는 이 장을 바탕으로 그 회사에 맞는 2~3개만 적습니다. 순위·숫자는 10/25 재출력 기준이며 10/26 확인용 재출력에서 바뀌면 갱신합니다.

## 1. 준비물 (거산 쪽, 소개서 기준·거산 확인 전)

| 구분 | 아연도금(전기아연도금) 후보에게 | 아노다이징 후보에게 |
|---|---|---|
| 보여 줄 공정 범위 | 철계 소재 백색·천연색·흑색·국방색 아연도금, 도금 두께 5 / 13 / 25 μm | 알루미늄 등 경질·백색·무광·유광·흑색·유색 피막, 실링(봉공처리) |
| 시험·측정 | 염수분무 시험(자체 실험실), X-ray 도금 두께 측정 | 내마모 시험·광택계, 염수분무 시험 |
| 인증·승인 | ISO 9001, AS9100D, 한화에어로스페이스 특수공정인증(SPA), ISO 14001·45001 | 위 + KSPC 한국특수공정인증, 아노다이징 피막 특허 |
| 실적(산업명만) | 방위산업, 자동차 부품 | 방위산업, 항공우주 |
| 가져갈 것 | 회사소개서, 해당 공정 시험 성적서 **종류**(값은 상대 요구에 맞춰), 인증서 사본, 샘플 처리 제안서(수량·일정은 상대와 합의) | 같음 |

- 인증서 번호·유효기간은 소개서 범위라 적어도 됩니다(거산 확인 2026-10-21). 연락처는 어디에도 적지 않습니다.
- 위 항목은 모두 "검수 기다림" 상태입니다. 거산이 확인해 준 것만 상대에게 말합니다.

## 2. 접촉 단계 (공통)

| 단계 | 하는 일 | 끝나면 기록할 것(도구) |
|---|---|---|
| 0. 접촉 전 확인 | 거래 관계(기존·신규·경쟁사), 자체 처리·외주 여부, 메모의 "확인할 질문" 답 | 거래 관계 표시, 확인 질문 답 |
| 1. 첫 접촉 | 공개 홈페이지의 대표 창구(문의 양식·대표 번호)로 구매·품질 담당을 찾음. 소개 + 상대 품목에 맞는 공정 2~3개 + 확인 질문 2개 | 담당자 의견 "접촉함", 결과 "응답 대기/회신" |
| 2. 샘플·시험 | 상대 품목 샘플로 처리 → 시험 성적서 제출(두께·내식·외관) | 결과 "샘플 처리 중" |
| 3. 등록·승인 | 협력사 등록 서류, 특수공정 승인 요구 확인(필요 시 고객 승인 절차) | 결과 "샘플·등록 승인 받음" |
| 4. 정식 제안 | 요구 사양·수량·일정 받은 뒤 제안 | 결과 "제안", 재접촉 일정 |

- 연락처는 담당자가 상대 홈페이지에서 직접 봅니다. 이 문서와 메모에는 적지 않습니다(CON-11).
- 2단계 이후의 단가·견적·납기는 거산이 정합니다. 도구와 메모는 다루지 않습니다(CON-23).

## 3. 메모 대상 5곳의 접촉 순서와 이유 (가설, 10/25 재출력 기준·동점은 판정한 배점 순)

| 순서 | 회사(공정) | 왜 이 순서인가 | 접촉 전에 꼭 확인할 것 |
|---|---|---|---|
| 1 | (주)명화금속 (아연도금) | 확인된 점수 50(순위 3위: 동점인 동화·코파스가 전부 판정해 앞). 철계 직결나사에 백색 전기아연도금 사양이 공개 카탈로그에 명시되어 공정 적합성이 가장 분명함 | 자체 도금 여부(열처리 설비 보유), 당진 사업장 직접 생산 여부, 거래 관계 |
| 2 | 코파스 주식회사 (아연도금) | 확인된 점수 50(순위 2위), 8항목 모두 판정 완료라 근거가 가장 탄탄함. 제품마다 도금 종류 선택 항목이 있어 도금 수요가 직접 확인됨 | 아연도금 물량이 실제로 있는지(특징 글은 니켈·흑착 중심), 아노다이징 물량 유무, 도금 외주 여부 |
| 3 | (주)대덕공조플랜트 (아노다이징) | 확인된 점수 48(순위 5위). 알루미늄 프로파일(센서 브라켓 등 산업용)로 아노다이징 소재·용도가 맞음 | 외주 수요 유무, 요구 피막·색상, 거래 관계. 10/25 재출력에 #108 근거 보강 반영됨 |
| 4 | 대덕과학기기 (아노다이징) | 확인된 점수 48(순위 4위). 레이저 실험장치 AL6061 베이스판으로 소재 명확. 수량은 적을 수 있음(장치 단위) | 연간 수량·반복성, 외관·치수 요구, 거래 관계 |
| 5 | (주)대영프로파일 (아노다이징) | 확인된 점수 48(순위 6위, 참고 72). 공고·채용은 "없음"으로 판정됨. DF 3090의 은색·흑색 선택이 외관 목적의 간접 근거라 적합성은 있으나 수요 신호가 약함 | 자체 처리 여부, DF 3090 현재 생산·판매 여부. **6위지만 메모 대상 유지(PM 결정 2026-10-25)** |

- 순서는 확인된 점수(E) → 근거의 분명함 → 수요 신호 순으로 PM이 매긴 **가설**입니다. 거산이 보기에 다른 순서면 그 이유를 기록합니다(판정 기록지 "연락할 만함 / 아님 / 모름").
- 동화경금속(2위)은 자체 코팅 라인 가능성 때문에 메모·접촉 대상에서 제외했습니다(#26). 거산 질문 E1.

## 4. 하지 않는 것 (CON-23·CON-11·CON-09)

- 단가·견적 금액·할인·원가를 적거나 계산하지 않는다.
- 납기·리드타임을 약속하는 문장을 쓰지 않는다.
- 경쟁사 이름·경쟁사 비교를 넣지 않는다.
- 상대에게 자동으로 메일·문자를 보내지 않는다. 접촉은 거산 담당자가 직접 한다.
- 상대·거산의 담당자 이름·전화·이메일을 어디에도 적지 않는다.
- 거산 내부 거래 이력·재접촉 입력값은 외부 AI에 넣지 않는다.
- 소개서에 없는 인증·실적을 "보유"로 쓰지 않는다. 소개서 값에는 "(소개서 기준·거산 확인 전)"을 붙인다.

- 위 5곳 순서에 동의하십니까? 다르다면 어떤 기준 때문입니까?
