질문별 **답변·상태** 칸에는 받은 답과 ‘응답 / 미확인 / 근거 대기 / 의견 / 미질문’을 적는다. 답이 없거나 묻지 못한 것을 ‘아니오’로 쓰지 않는다. **근거·다음 확인** 칸에는 확인할 자료, 후속 담당 역할, 기한을 적는다. 담당자 실명·연락처는 적지 않는다. 리허설의 연습 답변은 실제 방문 답변과 섞지 않는다.

## 판정 기록지 결과 집계

회사별 원본 판정은 기존 종이 기록지에 남기고, 이 부분에는 **개수만** 모은다. 공개 가능한 집계인지 PM이 확인한 뒤 공유한다. 집계 기준은 [성과 후보표의 숫자 규칙](../docs/kpi-plan.md)이다.

- 점수·순위 보기 전 판정했는가: 예 / 아니오 / 미확인
- 연락할 만함 ____곳 / 아님 ____곳 / 모름 ____곳 / 미응답 ____곳 — 합계 18곳
- 이미 거래 중 ____곳 / 경쟁사 ____곳 / 둘 중 하나에 해당해 제외할 곳 ____곳
- 거래 중과 경쟁사에 동시에 표시된 회사는 제외 개수에서 한 번만 센다. 빈 거래 칸은 ‘거래 없음 확인’으로 바꾸지 않는다.
- 가장 먼저 연락할 3곳의 원본 답은 별도 종이에 보관: 확인 / 미확인
- 도구 **상위 5곳** 중 연락할 만함 ____곳 / 아님 ____곳 / 모름 ____곳 / 미응답 ____곳 — 합계 5곳

‘도구 상위 5곳’은 메모 대상 5곳과 다를 수 있다. 최종 재출력 순위의 1~5위로 대조하며, 자체 설비 가능성 때문에 메모에서 빠진 회사를 다른 회사로 바꿔 세지 않는다.

도구 분류와 거산 판단의 비교는 PM이 비교 기준을 정한 뒤 적는다. ‘확인 필요’를 임의로 ‘아님’과 같은 뜻으로 바꾸지 않는다.

| 비교할 내용 | 기록 |
|---|---|
| 사용한 최종 재출력 자료의 날짜·규칙 버전 | |
| 비교 조건: 실제 확인 답을 반영한 재평가 / 가정 미리보기 / 비교 불가 | |
| 비교한 가정 단계와 분류 대응 기준 | |
| 비교 가능한 개수 / 일치 / 불일치 / 비교 제외 | |
| 공개 가능한 불일치 이유와 후속 질문 | |
| 공개할 개수·문구의 PM 확인 여부 | |

실제 답을 반영한 평가와 ‘확인했다고 가정한’ 미리보기는 따로 기록한다. 방문 답을 듣기 전 계산한 결과를 실제 거산 확인 결과로 적지 않는다.
