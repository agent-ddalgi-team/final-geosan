# 대덕과학기기 — 레이저 실험장치 베이스판 아노다이징

> **시연용 초안·거산 확인 전**
> 4위 · 기다리는 중 (확인 필요) · **접촉 후보 아님**
> 참고 점수 **57** · 확인된 점수 **48** / 판정한 배점 **85**
> 10/25 재출력 · 계산 기준일 2026-10-27 · 규칙 v0.17-b

## 1. 상대 회사 요약

대전의 실험장치·광학부품 개발·설계·제작 회사다. 검토 대상은 2023년 공식 카탈로그의 DSI-HNDEK-1 레이저 실험장치 베이스판(DSI-BP160×760-08)이다. 현재 생산 여부와 아노다이징 외주 발주는 확인 전이다.

## 2. 왜 추천하는가

카탈로그에 **AL6061·검정색 아노다이징** 사양이 있어 소재와 공정을 대조할 수 있다. 외관 목적은 검정색 사양에서 간접 추정했으며 반사 억제 성능을 확인한 것은 아니다. 도구는 확인된 점수 48 / 판정한 배점 85를 **참고 점수 57**로 표시한다. 유사 납품실적은 미확보이고, 10/25 확인한 공식 게시판 범위에서는 증설·수주·공고·채용 신호가 없었다. 거산 역량과 거래 관계 확인이 남아 있다.

## 3. 거산이 제공할 수 있는 것

알루미늄 아노다이징, 흑색 피막·실링, 내마모 시험·광택계가 소개돼 있다 **(소개서 기준·거산 확인 전)**. KSPC 한국특수공정인증도 같은 한정으로 제시할 수 있다 **(소개서 기준·거산 확인 전)**. 해당 베이스판의 합금·형상·색상·치수 충족을 보증하는 것은 아니다.

## 4. 확인할 질문

- **거산:** AL6061 검정색 아노다이징 베이스판의 요구 피막·색상·치수를 도면과 대조해 처리 가능 여부를 확인할 수 있습니까?
- **거산:** 기존 거래·중복 접촉 여부를 확인한 뒤 신규 검토 대상으로 삼아도 됩니까?
- **대덕과학기기:** 위 베이스판을 현재도 카탈로그와 같은 사양으로 생산합니까?
- **대덕과학기기:** 베이스판을 직접 가공합니까? 아노다이징을 별도로 외주 발주합니까?

## 5. 다음 할 일

거산의 공정·거래 관계 확인을 먼저 받는다. 상대의 현재 사양·외주 여부와 요구 조건을 확인할 경로를 정한 뒤, 확보한 답을 근거로 다시 평가한다.

## 6. 접촉 준비

- 알루미늄·흑색 아노다이징 **(소개서 기준·거산 확인 전)**.
- KSPC 한국특수공정인증 **(소개서 기준·거산 확인 전)**.
- 베이스판 외주 여부와 검정색 마감 목적·피막·치수 요구 확인.
- 반사 억제는 확인 전이며 필요 여부를 묻는다.
