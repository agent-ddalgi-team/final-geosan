# 코파스 주식회사 — 맞춤 메모

> **시연용 초안·거산 확인 전**
> 재료: 사실표(기준일 2026-10-27, 10/24 출력·순위표 3위), 사례 파일의 공개 홈페이지 근거. 10/26 저녁 재출력 뒤 바뀐 부분만 고칩니다.

## 1. 상대 회사 요약

- 충남 아산에서 볼트·너트·와셔·핀 등 특수 볼트를 만드는 제조업체입니다. 반도체 장비와 자동화장비 부품에 쓰입니다.
- 이번 기회는 **볼트·너트 전기아연도금**입니다.
- 거산과의 거래 관계는 확인 전입니다. 시스템 분류는 "기다리는 중 (확인 필요)"이며 접촉 후보가 아닙니다.

## 2. 왜 추천하는가

- 공개 홈페이지 제품 목록에 **재질 선택과 도금 선택 항목**이 있습니다. 도금은 "ZN-백색, ZN-천연색, 흑착(방청처리), KBN-무전해니켈(NI)"로 나옵니다. (출처: kofas.com/productK/)
- 소재는 SCM 435(크롬-몰리브덴 강), S 45C, SUJ2(핀류), SS400입니다. 철 계열이라 아연도금 대상이 됩니다. (출처: kofas.com/productK/)
- 반도체 장비용 품질 서류로 "SEMES 품질보증서 SSQ"를 홈페이지에 게시했습니다. (출처: kofas.com/board/?boardid=auth)
- 시점 신호는 약합니다. 확인된 증설 기록은 2017-12-12 "공장 확장 및 이전" 하나뿐입니다. (출처: kofas.com/sub01/03)
- 참고 점수 50입니다. 확인된 점수 50, 판정한 배점 100이며, 거산 확인 전이라 가정이 섞인 참고값입니다. 순위표의 3위도 같은 이유로 참고용입니다.
- **주의**: 아연도금은 홈페이지에서 **제품 선택 항목에만** 나옵니다. "코파스볼트 특징" 글은 고장력 렌치볼트에 **니켈(NI) 도금**을 쓴다고 설명하고, 흑착색보다 녹이 덜 슨다고 합니다. 실제 수요가 아연도금보다 니켈도금·흑착 쪽일 수 있어, 이 기회는 아연도금 후보로 두고 질문으로 확인합니다. (출처: kofas.com/sub03/01)

## 3. 거산이 제공할 수 있는 것 (소개서 기준·거산 확인 전)

- 전기아연도금: 백색·천연색·흑색·국방색, 도금 두께 5 / 13 / 25 μm, 처리 소재 철·알루미늄·구리 (소개서 기준·거산 확인 전)
- 시험·측정: 자체 염수분무 시험기, X-ray 두께측정기·도막두께 측정기 (소개서 기준·거산 확인 전)
- 인증: ISO 9001 (번호 ISO 9001-00022123-1, 2025-09-25 ~ 2028-09-24), AS9100D (번호 AS9100-00022123, 같은 기간) (소개서 기준·거산 확인 전)
- 니켈도금·흑착은 이 사실표의 거산 항목에 없어 **확인 필요**입니다.

## 4. 확인할 질문 (예/아니요로 답할 수 있게)

1. 볼트·너트의 백색·천연색 아연도금을 지금 외부 업체에 맡기고 계십니까?
2. 아연도금이 필요한 볼트·너트 품목이 따로 있습니까? (고장력 렌치볼트는 니켈도금이라고 안내하셨습니다.)
3. 흑착(방청처리)이나 무전해니켈 도금도 외주 대상입니까?
4. 알루미늄 볼트(AL7076)의 **아노다이징 물량**도 있습니까?

## 5. 다음 할 일

1. 거산이 소개서 값을 확인한 뒤 코파스를 다시 평가합니다.
2. 담당자가 위 질문 1~4 중 먼저 물을 것을 정합니다.
3. 거산이 니켈도금·흑착을 제공할 수 있는지 확인합니다. 필요하면 시연 뒤 별도 기회로 만듭니다.

## 6. 접촉 준비

- 먼저 말할 거산 공정: 백색·천연색 전기아연도금과 도금 두께 5 / 13 / 25 μm, 자체 염수분무 시험, ISO 9001·AS9100D (소개서 기준·거산 확인 전)
