# 코파스 주식회사 — 맞춤 메모

> **시연용 초안·거산 확인 전**
> 사실표 기준일 2026-10-27(10/27 재출력 확인, 순위·점수 변경 없음, 2위).

## 1. 상대 회사 요약

- 충남 아산에서 볼트·너트·와셔·핀 등 특수 볼트를 만듭니다. 반도체 장비와 자동화장비 부품에 쓰입니다.
- 이번 기회는 **볼트·너트 전기아연도금**입니다. 거산과의 거래 관계는 확인 전이고, 분류는 "기다리는 중 (확인 필요)"로 접촉 후보가 아닙니다.

## 2. 왜 추천하는가

- 제품 목록에 **재질·도금 선택 항목**이 있습니다. 도금은 ZN-백색, ZN-천연색, 흑착(방청처리), 무전해니켈(NI)입니다.
- 소재는 SCM 435, S 45C, SUJ2, SS400으로 철 계열이라 아연도금 대상입니다.
- 반도체 장비용 "SEMES 품질보증서 SSQ"를 게시했습니다. 확인된 증설은 2017-12-12 "공장 확장 및 이전" 하나뿐이라 시점 신호는 약합니다.
- 2위 · 참고 점수 50 = 확인된 점수 50 ÷ 판정한 배점 100. 거산 확인 전의 참고값입니다.
- **주의**: 아연도금은 제품 선택 항목에만 있고 특징 글은 니켈도금 중심입니다. 실제 수요는 질문으로 확인합니다.

## 3. 거산이 제공할 수 있는 것 (소개서 기준·거산 확인 전)

- 전기아연도금: 백색·천연색·흑색·국방색, 두께 5 / 13 / 25 μm
- 시험·측정: 자체 염수분무 시험기, X-ray 두께측정기
- 인증: ISO 9001 (ISO 9001-00022123-1, 2025-09-25 ~ 2028-09-24), AS9100D (AS9100-00022123, 같은 기간)
- 니켈도금·흑착은 사실표에 없어 **확인 필요**입니다.

## 4. 확인할 질문 (예/아니요로 답할 수 있게)

1. 볼트·너트의 백색·천연색 아연도금을 지금 외부 업체에 맡기고 계십니까?
2. 아연도금이 필요한 품목이 따로 있습니까? (고장력 렌치볼트는 니켈도금이라고 안내하셨습니다.)
3. 흑착(방청처리)이나 무전해니켈도 외주 대상입니까?
4. 알루미늄 볼트(AL7076)의 **아노다이징 물량**도 있습니까?

## 5. 다음 할 일

1. 거산이 소개서 값을 확인한 뒤 코파스를 다시 평가합니다.
2. 위 질문 중 먼저 물을 것을 정합니다. 니켈도금·흑착은 필요하면 시연 뒤 별도 기회로 봅니다.
