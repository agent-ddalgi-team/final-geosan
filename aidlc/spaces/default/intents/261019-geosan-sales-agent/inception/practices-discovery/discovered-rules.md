# 발견된 규칙 (Discovered Rules) — 거산케미칼 AI 영업지원 에이전트 2차

이 문서는 사람이 이미 기록에 확정해 둔 **딱딱한 제약**만 "항상 한다 / 절대 하지 않는다" 형태로 옮긴 **확정본**입니다. 새 규칙을 만들지 않았고, 각 줄 끝 괄호는 출처 제약 ID(제약 목록 `../../ideation/feasibility/constraint-register.md`) 또는 사용자 지시입니다. 인터뷰(Q1~Q5)에서는 새로운 딱딱한 제약이 나오지 않았습니다. 배포 시점·테스트 방식 같은 답은 "관행"이라 `team-practices.md`에만 적었습니다. 승인되면 `aidlc/spaces/default/memory/project.md`의 `## Mandated` / `## Forbidden`에 날짜와 함께 추가됩니다.

## Mandated

- ALWAYS 기획서 5장과 부록 F의 점수·분류 규칙 수치를 그대로 쓰고, 필수 판정(필터)을 생략하거나 점수로 우회하지 않는다. (사용자 지시; 범위 문서 P0-3, 6절)
- ALWAYS 가상 데이터(가상 검수 데이터, A정밀·아연도금 가상 사례)는 화면과 모든 출력물에 "가상·거산 실제 사양 아님"으로 표시한다. (CON-10, CON-20; 범위 문서 P1-4)
- ALWAYS 외부 LLM으로 본문을 보내기 전에 그 내용이 공개 자료(공고·홈페이지 본문)인지 확인하는 검사를 거친다. (CON-09)
- ALWAYS 홈페이지 본문을 자동 수집할 때 robots.txt와 이용약관을 지킨다. (범위 문서 P0-4; CON-07)
- ALWAYS 자동 수집 외부 소스는 3개(산단공 공장현황 CSV + 공장등록생산정보 API, 특정수질유해물질 업체정보 CSV, 나라장터 입찰공고 API) 안에서만 설계한다. (CON-04)

## Forbidden

- NEVER 거산 내부 이력·재접촉 입력 필드를 외부 LLM이나 외부 서비스로 전송하지 않는다. 재접촉 흐름은 규칙 계산만 한다. (CON-09; 범위 문서 P1-1)
- NEVER 개인정보(담당자 이름·이메일·전화 등 연락처)를 저장하지 않는다. 데이터 모델에 연락처 열을 두지 않는다. (CON-11)
- NEVER 기업 홈페이지·보도자료에서 이메일·전화 등 연락처를 자동 수집하지 않는다. (CON-07)
- NEVER 채용 공고 사이트와 유료 기업 DB를 수집 소스로 연결하지 않는다. (CON-08)
- NEVER 단가·견적금액 산정, 납기 확정, 고객 자동 발송, 가격·사업모델·경쟁사 비교 기능을 만들지 않는다. (CON-23)
- NEVER 자격증명·API 키를 코드에 직접 적지 않는다. 환경 변수나 비밀 관리 수단으로 넘긴다. (구현 단계 지침 `phases/construction.md` Security; 조직 공통)
