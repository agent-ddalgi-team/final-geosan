# Bolt 계획 (Bolt Plan) — 거산케미칼 AI 영업지원 에이전트 2차

"Bolt"는 한 번의 구현 묶음입니다. 작업 단위(`../units-generation/unit-of-work.md`) 하나를 골라 설계·코드 생성·테스트를 한 바퀴 돌려 **돌아가는 결과**를 내고, 사람이 확인(체크포인트)한 뒤 다음 Bolt로 갑니다. 확인된 답변(`delivery-planning-questions.md` Q1~Q4)대로 Bolt 하나 = 작업 단위 하나이고, 순서는 걷는 뼈대(가장 작은 끝단 조각을 먼저 끝까지 돌려 구조가 이어지는지 확인하는 방식) → 이정표 조건 → 가치·위험 혼합입니다. 의존 그래프(`../units-generation/unit-of-work-dependency.md`)를 어기는 순서는 없습니다. 팀 실천 방식: 트렁크 기반, Bolt 하나가 `main`에 스쿼시 커밋 하나, 테스트는 시나리오 먼저.

**계획의 전제(아직 확인 안 됨)**: 평일 하루 8시간·주말 4시간을 팀원 3명과 아직 합의하지 않았다(Q4 E). 합의가 바뀌면 이 계획의 날짜를 다시 계산한다. PM(최지예)은 거산 소통·팀 조율·AI-DLC 진행·PR 확인을 맡아 개발 여력 50%로 잡았다. **(갱신 2026-10-21)** 10/21 오전 팀 회의에서 합의를 확인한다. B1은 10/21 시작으로 당겼고 뼈대 기간 80% 기준 계산은 `b1-change-proposal-20261021.md` 5장에 있다(가용 약 156h vs 필요 약 132h, 제약은 시간보다 "얇은 조각 → 팀원 개발" 순서).

### B2 — U2 근거 추출·전송 보호 (10/29~11/4, 짝 1)

## 7. 구현 담당과 결정 지점 (사용자 지시, 2026-10-21)

1. **구현 방식 (갱신 2026-10-21)**: 뼈대(B1, U1)의 **얇은 끝단 조각(A정밀 1건이 파일 투입 → 평가 → 목록·상세 → 의견 저장까지 돌아가는 최소 코드)은 이 AI-DLC 세션의 개발자 에이전트가 먼저 만들고**(단위 소유: solo, 10/21~10/22), 그 뒤 팀원 3명이 각자 Claude Code/Codex로 자기 모듈(규칙 엔진 / DB·API·명령 / 화면)을 넓히는 PR을 올려 10/28까지 뼈대를 완성한다. 뼈대 체크포인트(검증 명령 + 시연)는 합쳐진 `main` 기준으로 PM이 승인한다. 팀원은 AI-DLC 진행·승인을 하지 않는다.
