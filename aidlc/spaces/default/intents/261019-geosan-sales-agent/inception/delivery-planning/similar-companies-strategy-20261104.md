# 비슷한 회사 참고 — 같은 공정·산업군의 메모·영업 진행을 참고 자료로 (PM 결정 2026-11-04, A안, 2차)

**상태**: PM 결정(A안 + 영업 전략 영역에서도 참고, 2차 보강 11/17 이후). 약속 파일은 2차 시작 때 PM이 더한다(3장). 이슈 #268(서버 이강욱)·#269(화면 고선주), 영업 전략 영역은 #27. 근거: PM 요청 "동일 산업군·공정·역량의 메모 내용이나 영업 진행 정도에 따라 참고할 수 있는 자료로"(2026-11-04).

## 0. 한 줄 결론

상세 화면에 **"비슷한 회사 참고"** 영역을 두어, 같은 공정 또는 같은 산업군 회사 최대 5곳의 영업 단계·거절 이유·마지막 접촉·최근 메모 한 줄을 보여 준다. 영업 전략 영역(2차, #27)에서는 같은 자료의 **요약(건수)**을 "참고한 이력" 상자로 초안 옆에 둔다. 모두 **프로그램 안 조회**이고 메모는 밖으로 나가지 않는다. AI가 메모를 읽고 제안하는 것은 #247(가/나/다) 결정 뒤 별도.

## 1. 무엇을 보여 주나

| 항목 | 값 | 출처 |
|---|---|---|
| 비슷한 회사 고르기 | 같은 공정 코드 우선 → 같은 산업군 → 영업 단계가 앞선 순 → 최근 기록 순. 본인 제외, 최대 5곳. 가상 회사는 실제 회사와 섞지 않음 | 카드 `processCodes`·`industries` |
| 곳마다 | 회사명 · 공정 · 산업군 · 최신 영업 단계(거절이면 거절 이유) · 마지막 접촉일·방법 · 최근 메모 한 줄(120자) · 담당자 | 기록 표(단계·접촉·메모·답) |
| 요약 줄 | 같은 공정 n곳 · 산업군 m곳 / 단계별 건수 / 거절 이유 상위 3 / 접촉 방법별 연결 비율 | 같은 표, 건수만 |

예: "코파스 · 전기아연도금 · 자동차 부품 · 접촉 중 · 11/06 전화 · 메모: 납기 걱정, 샘플 먼저 요청 — 박 이사"

## 2. 화면 모양 (고선주, #269)

- [상세 › 기록 영역 옆 "비슷한 회사 참고"] 요약 줄 1개 + 회사 줄 최대 5개. 회사명을 누르면 그 회사 상세. 0곳이면 "같은 공정·산업군의 다른 회사가 아직 없습니다".
- [상세 › (4) 영업 전략(2차, #27)] 전략 초안(공개 자료 기반 AI) 옆에 **"참고한 이력"** 상자: 요약 줄 + 비슷한 회사 2곳. "내부 참고 · 밖으로 안 나감" 표시. 초안 글과 섞지 않는다.
- 보기 전용 담당자도 볼 수 있다(읽기). 메모는 담당자 전원이 보는 규칙(11/3 Q4) 그대로.

## 5. 시기와 순서

- 2차 보강(11/17 이후). 거절 이유 코드(#250·#251)와 거래 관계 입력(#265·#266)이 1차에 들어가므로 2차 시작 때 바로 쓸 자료가 있다.
- 순서: #268 → #269(참고 영역) → #27 전략 영역에 상자. 대시보드 집계(#229)에는 거절 이유 분포만 +2h로 더한다(#229 댓글로).

## 6. 안 하는 것

- 메모 본문을 AI에 보내 "이 업종은 납기 걱정이 많다" 같은 제안을 만드는 것 → #247 결정 뒤. (가) 금지 유지면 이 제안서의 내부 조회까지만.
- 회사 간 메모 전체 검색(C안)은 거산이 메모를 쌓은 뒤(12월) 필요하면.
