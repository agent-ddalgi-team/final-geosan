# 추천 목록 지역·산업 선택 (PM 결정 2026-11-03 밤)

> 상태: **PM 결정 완료, 약속 파일 반영 완료(계약 요약 v2, 더하는 변경).** 공정 탭(`process-tabs-20261103.md`)에 이어 같은 밤 결정. 코드는 #209(API)·#210(선택 UI)·사례 파일 산업군 손 입력(새 이슈) 1차.

## 0. 한 줄 결론

추천 목록에서 **공정 탭 → 지역 선택 → 산업 선택**을 겹쳐 걸러 결과 목록을 본다. 지역은 좌표·API 없이 **주소 글자의 시·군**으로 거르고 "천안 인근"(천안시·아산시) 묶음을 맨 앞에 둔다. 산업은 **사례 파일 18곳에 사람이 산업군을 적어** 거른다(AI 제안 #229와 km 거리 #222는 2차 그대로). 점수·순위 규칙은 바뀌지 않는다.

## 1. 화면 (추천 목록 S1)

```
| 추천 목록        [전기아연도금 (9) | 아노다이징 (10)]                                  |
| 지역 (전체 ▾ 천안 인근 8 · 천안시 3 · 아산시 5 · 당진시 4 · 대전 5 · 세종 1)             |
| 산업 (전체 ▾ 자동차 부품 n · 방위산업 n · … )   [🔍 회사·기회·산업군 검색]  정렬: 추천 순 |
| 1  코파스 · 볼트·너트 전기아연도금  [전기아연도금] [아산시] [자동차 부품]  [지금 바로…] 81 |
```

- 지역·산업은 드롭다운(모달 없음) 하나씩. 고르면 `?process=&region=&industry=`로 다시 불러 순위 번호가 그 결과 안 1, 2, 3…. 주소에 조건을 남겨 새로 고침·공유해도 유지.
- 선택지 옆 건수는 현재 공정 탭 안 건수(`meta.regionCounts`·`industryCounts`). 0건은 숨김.
- 결과 0건: "이 조건에 맞는 후보가 없습니다. 지역·산업을 '전체'로 바꿔 보세요".
- 지역 미확인(주소 없음)·산업 미확정은 "전체"에서만 보이고, 카드 꼬리표에 "지역 미확인"/"산업 미확정".

## 2. 지금 상태 (확인 2026-11-03)

| | 지금 | 결정 |
|---|---|---|
| 지역 | km 거리·30/50/100km 필터(#222, 2차). 도로명주소 API 승인키 대기 | 1차는 주소 시·군 글자. 18곳 = 천안 3 · 아산 5 · 당진 4 · 대전 5 · 세종 1 |
| 산업 | 회사에 산업군 칸 없음. AI 제안 + 칩 확정은 2차 #229 | 1차는 사례 파일 `customer.industries`(설정 10개 안, ≤3)를 사람이 적음. 출처 CASE_FILE |
| 검색 `q` | 고객명·기회명 | 산업군 이름도 |

시·군 뽑는 규칙: 첫 어절이 광역시·특별시·세종특별자치시면 그 이름(대전, 세종), 아니면 둘째 어절(천안시·아산시·당진시). 저장하지 않고 응답 조립 때 계산(주소가 바뀌면 따라 바뀜).
