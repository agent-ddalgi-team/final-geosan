# 연락처 규칙 변경 — 영업 메모에 연락처 허용, 회사 대표번호 자동 표시 (PM 지시 2026-11-03)

**상태**: PM 지시로 반영. 약속 파일(계약 요약 v2)·AGENTS.md·이슈 #209·#210·#217·#219·#220·#221에 적용.

## 0. 한 줄 결론

프로그램을 **거산 담당자가 영업할 때 직접 연락하려고 쓰는 내부 메모장**으로 본다. 그래서 (1) 공개된 회사 대표번호는 상세 화면에 자동으로 보이고, (2) 영업 메모에 상대 회사 담당자 전화·이메일을 적어도 된다. 대신 메모와 번호는 **밖으로 한 걸음도 안 나간다**(외부 AI·웹 검색·엑셀·질문 목록·저장소 파일·이슈).

## 1. 무엇이 바뀌나

| | 전(CON-07·CON-11, 2026-10-19) | 후(2026-11-03) |
|---|---|---|
| 회사 대표번호 | 저장·표시 안 함 | 공개 홈페이지 본문(U2 근거 추출)·산단공 CSV(U3)에서 **자동으로 채워** 상세 머리에 표시. 사람 입력 칸은 없음 |

| 이슈·PR·문서 | 연락처 안 씀 | 그대로 |

## 2. 왜 괜찮은가 / 조건

- 회사 대표번호는 법인의 공개 정보라 개인정보가 아니다. 공개 홈페이지·공공 CSV에 이미 있는 값을 그대로 보이는 것이다.
- 상대 회사 **담당자** 이름·휴대폰은 개인정보다. 그 값은 **거산 담당자가 명함·통화에서 얻어 직접 적는 것**만 들어오고, 프로그램이 모으지 않는다. 거산이 지금 명함·전화부로 하는 관리를 프로그램 메모로 옮기는 것이라, 보관 책임은 거산에 있다. **전달 메일(#220)에 한 줄로 알린다**: "영업 메모에 적은 연락처는 거산이 관리하는 개인정보입니다. 프로그램 밖으로 내보내지 않으며, 불필요해지면 지워 주세요."
- 조건 3가지: ① 접속 보호(U8 #213)가 켜진 환경에서만 실제 연락처를 적는다(시연 노트북·팀 PC DB에는 적지 않음). ② 실제 기록은 거산 지정 환경(CON-13). ③ 지우기 없음(Q5)이지만, 개인정보 삭제 요청이 오면 운영 명령으로 지우는 길이 필요 — 2차 보강에서 `geosan note-delete`(사유 기록) 검토.
