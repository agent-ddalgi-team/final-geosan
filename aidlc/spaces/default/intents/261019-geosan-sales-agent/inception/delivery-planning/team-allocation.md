# 팀 배정 (Team Allocation) — 거산케미칼 AI 영업지원 에이전트 2차

"Bolt"는 한 번의 구현 묶음(작업 단위 하나를 설계·코드 생성·테스트까지 돌려 돌아가는 결과를 내는 것)입니다. 이 프로젝트는 범위 mvp라 팀 구성 단계(1.5)를 건너뛰었으므로, **모든 Bolt의 코드는 개발자 에이전트(이 AI-DLC 세션의 aidlc-developer-agent)가 만들고**, 사람 4명은 검토·승인·파일 작성·거산 소통을 맡습니다. "짝"은 사람 2명이 하나의 Bolt를 함께 보는 단위이고, 동시에 진행하는 Bolt는 최대 2개(11/9 주에 한해 파일이 겹치지 않는 Bolt 1개를 3개째로 허용)입니다.

## 3. 승인과 확인 방식

- **체크포인트 승인**: 각 Bolt가 끝나면 엔진이 검증 명령을 돌리고 PM이 승인한다(설정: 단위 하나씩·순차·체크포인트). 뼈대(B1) 승인은 사람이 직접 하며, 그 뒤 "자동으로 이어갈지, 매번 검토할지"를 한 번 묻는다(팀 실천 방식).
- **PR 확인**: 모든 PR은 PM 또는 짝의 다른 사람이 읽는다. 체크리스트: 테스트 통과, 시나리오 번호, "약속 파일을 바꿨나요?", 가상 데이터 표시.
- **동시 2개 규칙**: 같은 파일을 많이 고치는 쌍(U4·U5, U2·U5, U6·U7)은 같은 주에 두지 않았다. 11/9 주의 3개째(B9)는 안내서·예시·백업 명령만 만든다.
- **합치기**: 1~2일마다 `main`에 스쿼시 커밋. 마이그레이션은 접두사별 파일, 머리가 둘이면 `geosan db merge-heads`.

## 4. 사람 밖 자원

- 개발자 에이전트(AI)는 이 세션에서 Bolt 순서대로 코드를 만들고, 각 Bolt의 설계 산출물(기능 설계 등, 범위에 따라)을 먼저 만든다.
- 팀 밖 검증자 1명(사관학교 동료 또는 멘토): 11/13 전 안내서 시험과 사용성 과제(10분).
- 거산 담당자: 11/15 접속·의견 기록, 11월 말 방문 확인.
