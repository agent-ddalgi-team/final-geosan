# 검토사항 "자료 못 찾음·자료 부족" 줄 보완 — 메모 적기 + 붙여넣고 조사 (PM 결정 2026-11-04, 2차)

**상태**: PM 결정(둘 다 2차 보강 11/17 이후, 선택 기능). 약속 파일은 2차 시작 때 PM이 더한다(3장). 이슈 #259(서버 이강욱)·#260(화면 고선주). 근거: PM 질문 "자료 부족 줄도 담당자가 찾아서 링크나 내용을 적으면 활용할 수 있지 않나"(2026-11-04).

## 0. 한 줄 결론

검토사항의 자료 줄("자료 못 찾음"·"자료 부족")에 담당자가 찾은 것을 붙이는 길을 둘로 둔다. **(1) 메모 적기** — 링크·내용을 자료 조사 메모로 남긴다(기록용, 점수 영향 없음). **(2) 붙여넣고 조사** — 공개 본문을 붙여 넣으면 AI가 근거를 뽑아 재평가한다(점수에 반영). 둘 다 선택이며 체크·답 적기와 독립이다.

## 1. 왜 둘로 나누나

| | (1) 메모 적기 | (2) 붙여넣고 조사 |
|---|---|---|
| 무엇이 남나 | 담당자 글(링크·요약) | AI가 뽑은 근거(미확인 후보)·질문·회사 요약 |
| 점수·분류 | 안 바뀜 | 재평가로 바뀔 수 있음 |
| 밖으로 나가나 | 안 나감(메모와 같은 내부 전용) | 붙여넣은 본문이 OpenAI로 나감 → **공개 자료만** |
| 쓰는 때 | 통화로 들은 사실, 나중에 볼 단서 | 홈페이지 글·공고처럼 공개된 본문을 찾았을 때 |
| 새로 만드나 | 메모 요청에 "어느 줄" 칸만 | 약속 파일에 이미 있는 조사 요청(pastedText) 그대로, 단추만 |

메모를 근거로 자동 승격하지 않는다. 사람이 적은 글이 점수를 바꾸는 길은 사례 파일(기존)뿐이다.

## 2. 화면 모양 (고선주, #260)

- [상세 › 검토사항 › 자료 줄] 글 옆에 **[메모 적기]** **[붙여넣고 조사]** 두 단추. 질문 줄에는 없음(질문 줄은 [답 적기]).
- [메모 적기] 질문 줄 [답 적기]와 같은 인라인 입력(500자). 저장하면 줄 아래 "메모: 홈페이지 연혁에 2023 납품 기재 https://… — 박 이사 · 11/20". 링크는 새 창. 메모가 있으면 [메모 고치기](최신 메모로 덮어씀, 이전 메모는 활동 이력).
- [붙여넣고 조사] 인라인 칸 2개: 출처 주소(공개 홈페이지·공고 주소, 확정된 홈페이지가 있으면 미리 채움)·공개 본문. 안내 "공개 자료만 됩니다. 붙여넣은 글은 AI에 보내 근거를 뽑고 다시 평가합니다 · 이번 달 N/1,000회". [조사] → 성공 "근거 2건(확인 필요 1건 포함)·질문 1건 저장, 재평가 완료" + 상세 새로 불러오기. 실패는 C1 `/homepage` kind별 동작(한도 잠금·설정 오류 잠금·다시 시도).
- [잠금] 담당자 없음·보기 전용은 둘 다 잠김. 조사 중에는 다른 줄의 [조사]도 잠김(한 번에 하나).
- 체크는 자동으로 바뀌지 않는다. 자료를 보완했으면 담당자가 체크한다.

## 3. 약속 파일 변경 (모두 더하는 변경, 2차 시작 때 PM이 적음)

| 어디 | 무엇 |
|---|---|
| C1 `POST /opportunities/{oppId}/notes` | 선택 칸 `itemId`(검토사항 줄 번호). 종류 RESEARCH만 허용(아니면 400), 현재 검토사항에 없는 줄이면 404, 질문 줄(`Q:`)이면 400(답 적기로) |
| C1 `reviewItems[]` | 자료 줄(DATA_NOT_FOUND·DATA_INSUFFICIENT)에 `note: { text, by, at } \| null`(그 줄의 최신 자료 조사 메모) |
| C1 `POST /homepage` | 변경 없음. `url` + `pastedText`로 호출(출처 주소는 필수: 저장된 홈페이지가 없으면 화면이 받음) |
| C4 | 줄에 붙은 메모는 NOTE와 같은 취급(이미 적용). 붙여넣은 본문은 EXTERNAL_AI 규칙(연락처 제거·공개 자료만) 그대로 |
| C6 `rec_note` | `item_id`(String 64, nullable) 열. 활동 이력 요약 앞에 줄 글 |
| C0·C7 | 없음 |

깨는 변경 없음.
