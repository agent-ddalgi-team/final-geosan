# 추천 목록을 공정별 탭으로 (PM 결정 2026-11-03 밤)

> 상태: **PM 결정 완료, 약속 파일 반영 완료(계약 요약 v2, 더하는 변경).** 코드는 #209(목록 API)·#210(탭) 1차.

## 0. 한 줄 결론

이전 시연은 전기아연도금과 아노다이징 후보를 **한 줄 순위로 섞어** 보여 줬다. 거산 영업은 공정별로 진행하므로 **추천 목록을 공정 탭으로 나누고 순위도 공정 안에서** 매긴다. 점수·분류 규칙은 그대로이고, 정렬 뒤 번호를 공정 안에서 다시 붙일 뿐이다. 대시보드·조사·수집·영업 기록의 공정별 구분은 이번에 넣지 않는다(PM 결정: 목록 탭만, 1차).

## 1. 화면 (추천 목록 S1)

```
| 추천 목록        [전기아연도금 (9) | 아노다이징 (10)]   ← 재접촉 탭 자리(U6 보류) |
| [🔍 검색]                        정렬: 추천 순서 | 가까운 순                        |
| 1  코파스 · 볼트·너트 전기아연도금   [전기아연도금]  [지금 바로 연락 검토] 81 … |
```

- 탭은 기회가 1건 이상인 공정만, 역량 파일 순서. 처음 여는 탭은 첫 공정.
- 순위 번호는 탭 안에서 1, 2, 3…. 한 회사가 두 공정에 걸리면 두 탭에 모두 나온다(기회 1건 = 공정 연결 여러 개 가능).
- 카드에 공정 꼬리표(역량 파일 이름, "— 가상" 꼬리는 뗀다).
- 대시보드 건수를 눌러 목록으로 올 때(`?stage=`)는 탭 없이 전체(공정 섞임). 공정 탭은 추천 목록 화면에서만.
