## 1. 가능한가 — 파일 투입 방식 vs 자동화 일부 당기기

**결론: PM 생각대로 "뼈대의 파일 투입 경로"로 한다.** 승인된 문서와 어긋나지 않고, 11/15 대체 시연 기준(요구사항 A12·FR4.14: 소개서 묶음 평가 + "거산 확인 전" 띠 + 확인 대기 질문 목록, 접촉 승인 불가)을 10월 말에 작은 규모(10~20곳)로 먼저 돌리는 것이기 때문이다.

### 1-1. 왜 되는가 (승인 문서 기준)

| 필요한 것 | 뼈대(U1)에 이미 있는가 | 근거 |
|---|---|---|
| 실제 기업·기회를 파일로 넣기 | 있음. `geosan import-case <file.json>`(C8), CaseFile(C7)은 고객·기회·근거·요구·신호·항목 입력값을 한 묶음으로 받음 | contract-summary C7·C8, FR6.6 |

| 제안 | 내용 | 약속 파일 |
|---|---|---|
| ① 빈 템플릿 | `examples/case-template.json`: 칸마다 `_설명`에 "무엇을 적는지 · 허용 값 · 예". 8항목 판정 칸에는 단계값·확실도 기준(부록 A.1·A.3) | 없음 |
