# 거산과의 거리 표시 + 지도앱 링크 — 기능 추가 제안 (2026-11-03)

> 상태: **초안, PM 결정 대기.** PM 요청(2026-11-03): 회사 주소를 좌표로 바꿔 거산케미칼과의 직선거리(km)를 목록·상세에 보이고, 가까운 순 정렬·거리 필터만 둔다(점수에는 넣지 않음, 차로 가는 거리는 안 만듦). 상세 화면에 [네이버 지도에서 보기] [카카오맵에서 보기] 버튼을 주소 링크로만 만든다(API 키 없음). 아래는 약관·링크 형식 확인 결과, 전송 보호 처리, 작업 시간·묶음, 약속 파일에 더할 것이다. 반영 순서는 팀 규칙대로 약속 파일 → PR 체크리스트 → 코드.

## 0. 한 줄 결론

- **지오코딩은 행정안전부 도로명주소 "좌표제공 API"를 추천**한다. 저장 금지 문구가 없고 승인 신청 때 용도를 적어 확인받을 수 있다. 브이월드 지오코더는 "실시간 사용, 저장 불가"가 명시돼 있어 쓰지 않는다.
- **지도앱 링크 두 개는 지금 형식이 맞다**(2026-11-03 브라우저로 확인). 단, 카카오맵은 "충청남도"처럼 도 이름을 길게 쓰면 결과가 없으므로 주소를 "충남 …" 또는 시·군부터 넣는다.
- 작업 시간 어림 **약 23시간**(지도 링크 1시간 + 거리 22시간). 지도 링크는 **U5 화면**에, 거리는 **U7에 붙는 소단위**로 두되 전송 보호 부품(U2)이 생긴 뒤 붙인다.

## 1. 지오코딩 소스 비교 (약관에서 좌표 저장이 되는가)

| 항목 | 브이월드 지오코더 API 2.0 (국토교통부) | 도로명주소 좌표제공 API (행정안전부, juso.go.kr) |
|---|---|---|
| 좌표 저장 | **불가.** 안내문 원문: "API 요청은 실시간으로 사용하셔야 하며 별도의 저장장치나 데이터베이스에 저장할 수 없습니다." | **금지 문구 없음.** API 안내 페이지와 사이트 이용약관에 저장·가공 금지 조항이 없다(이용약관은 사이트 자료의 무단 상업 이용·재배포만 금지). 승인 신청서에 용도("회사 주소 좌표를 저장해 거산과의 거리 계산, 내부용")를 적어 승인받는다 |
| 키 | 인증키 필요(브이월드 회원, 도메인 등록) | **승인키**(신청·심사). 좌표제공 API와 도로명주소 검색 API 키가 따로이며, 검색 API 키로는 좌표 API를 못 쓴다(오류 E0001). 시험용 키 `TESTJUSOGOKR` 있음 |
| 하루 한도 | 40,000건 | 안내 없음(비정상 연속 호출 제한만). 우리는 설정값으로 하루 상한을 둔다 |
| 입력 | 주소 문자열 한 줄(지번/도로명 구분) | **2단계.** ① 도로명주소 검색 API에 주소 문자열 → 행정구역코드·도로명코드·건물번호 ② 좌표제공 API에 그 코드들 → 좌표 |
| 출력 좌표계 | EPSG:4326(위경도) 기본 | `entX`·`entY` = EPSG:5179(UTM-K). **위경도 변환 필요**(변환 공식 또는 `pyproj` 패키지 1개) |
| 우리 쓰임새와 맞는가 | 좌표를 저장 못 하면 목록을 열 때마다 50곳을 다시 호출해야 해 부적합 | 좌표를 회사 행에 저장해 두고 거리는 조회 때 계산. 적합 |

**추천: 도로명주소 좌표제공 API.** 승인이 며칠 걸릴 수 있으니 PM이 먼저 신청한다. 승인 전에는 시험용 키로 개발하고, 18곳 좌표는 승인 뒤 한 번에 채운다.

산단공 전국등록공장현황 CSV에 좌표 열이 있으면 지오코딩이 아예 필요 없다. U3(유동렬)가 CSV 열을 확인해 있으면 그 값을 쓰고, 없을 때만 API를 부른다(확인 필요).

## 2. 지도앱 링크 형식 확인 (2026-11-03, API 키 없이 브라우저로 열어 봄)

| 앱 | 링크 형식 | 확인 결과 |
|---|---|---|
| 네이버 지도 | `https://map.naver.com/p/search/{주소 URL 인코딩}` | 거산 본사 주소로 열면 제목이 "… 봉주로 303-1 검색 - 네이버지도"이고 장소 "거산케미칼"이 보임. "충청남도 …" 긴 주소도 됨 |
| 카카오맵 | `https://map.kakao.com/link/search/{주소 URL 인코딩}` (카카오 공식 Web API 가이드의 "지도 검색결과 바로가기") | `map.kakao.com/?q=…`로 넘어가 주소 1건 + 장소 "거산케미칼"이 보임. **단 "충청남도 천안시 …"로 넣으면 "검색 결과가 없어요"**, "천안시 서북구 봉주로 303-1"·"충남 천안시 …"는 됨 |
| 앱 스킴(`nmap://`, `kakaomap://`) | 쓰지 않음 | 네이버는 `appname` 필수에 앱 설치가 전제, 카카오도 앱 전용. 웹 링크는 PC·모바일 모두 브라우저로 열린다 |

**주소 정규화 규칙(화면에서)**: 도 이름을 약칭으로 바꾼다(충청남도 → 충남, 경기도 → 경기 …) 또는 시·군부터 넣는다. 두 링크 모두 새 창(`target=_blank`, `rel=noopener`)으로 연다. 서버를 거치지 않고 화면이 주소로 링크를 만들므로 **약속 파일 변경이 없다.**

## 3. 전송 보호 (지오코딩 API로 나가는 것은 주소뿐)

C4 `check_transfer`에 용도를 하나 더 둔다. 네이버 검색용 `EXTERNAL_SEARCH`와 같은 꼴이다.

```yaml
EXTERNAL_GEOCODE:   # (제안 2026-11-03) 도로명주소 검색·좌표제공 API로 나가는 주소
  - 허용 kind: CUSTOMER_ADDRESS (산단공 공개 CSV 출처, securityGrade PUBLIC)만. 회사명도 보내지 않는다(주소만으로 충분)
  - 그 밖의 kind(NOTE, INTERNAL_HISTORY, CUSTOMER_RELATION, CAPABILITY_VALUE, 연락처)가 섞이면 전체 거부
  - kind·securityGrade 없음·UNKNOWN → 거부
  - 하루 호출 상한(geocoding.dailyCallLimit) 초과 → 거부 (kind GEOCODE_LIMIT, "오늘 좌표 변환 한도 초과")
  - sideEffect: TransferLog 1행(kind GEOCODE, 시각·고객 ID·호출 수, 주소 본문 없음)
```

- 거산 주소 자체는 공개 자료(회사소개서, 연락처 아님)라 외부 전송·저장에 문제가 없다. 그래도 매번 보내지 않고 **PM이 한 번 좌표를 구해 설정 파일에 적어 둔다.**
- 저장하는 것은 회사 행의 `lat`·`lng`·`geocodedAt`·`geocodeSource`뿐. 거리는 저장하지 않고 조회 때 계산한다(거산 좌표가 바뀌어도 재계산 없음).
- CON-07(연락처 자동 수집 금지)·CON-09(내부 이력 외부 전송 금지)와 충돌 없음. 지오코딩 API는 좌표만 돌려주고 연락처를 주지 않는다.

## 4. 거리 계산·표시 규칙 (제안)

- 직선거리: 위경도 두 점의 구면 거리(하버사인) km, 소수 1자리. 점수·분류·정렬 규칙(부록 F)에는 **들어가지 않는다**(규칙 엔진 입력 아님).
- 목록: 카드 작은 글씨에 "거산에서 12.3km". 정렬 선택 `가까운 순`(기본은 지금 순위순 그대로), 필터 `거리 ○km 이내`(선택지는 설정값 `distanceFilterPresetsKm: [30, 50, 100]`).
- 좌표가 없는 회사: "거리 미확인"으로 표시하고 가까운 순 정렬에서는 맨 뒤. 필터를 걸면 제외.
- 상세: 머리에 거리 + [네이버 지도에서 보기] [카카오맵에서 보기].
- 가상 사례(A정밀 등)는 주소가 가상이면 좌표를 구하지 않고 "가상·거리 없음".

## 6. 약속 파일에 더하는 것 (모두 더하는 변경)

| 계약 | 더할 것 |
|---|---|
| C1 `/opportunities` | 조건 `sort: enum[rank, distance]`(기본 rank), `maxDistanceKm: number`. 카드에 `distanceKm: number | null` |
| C1 `/opportunities/{oppId}` | 머리에 `distanceKm`, `address`(지도 링크는 화면이 주소로 만듦) |
| C4 | 용도 `EXTERNAL_GEOCODE`(3장) |
| C6 | 고객 테이블 열 `lat`, `lng`, `geocodedAt`, `geocodeSource: enum[JUSO, CSV, MANUAL]` |
| C7 AppSettings | `geosan: { address: string, lat: number, lng: number }`(PM이 적음), `geocoding: { provider: JUSO, enabled: boolean, dailyCallLimit: int }`, `distanceFilterPresetsKm: [int]` |
| C8 | `geosan geocode [--missing-only]`: 좌표 없는 회사만 변환, 건수·실패 사유 출력 |
| C9 | `GeocodeAdapter`: `geocode(address) -> { lat, lng, source, matchedAddress } | null`, 키 `JUSO_SEARCH_KEY`·`JUSO_COORD_KEY` 환경 변수, timeout 10s, retry 1 |
| `.env.example` | `JUSO_SEARCH_KEY=`, `JUSO_COORD_KEY=` 이름만 |

의존성: 좌표 변환에 `pyproj` 1개를 더하거나(정확), 변환 공식을 코드로 두거나(패키지 없음, 수십 m 오차 허용). 직선거리 표시 용도라 **공식 쪽을 추천**(패키지 추가 없음).
