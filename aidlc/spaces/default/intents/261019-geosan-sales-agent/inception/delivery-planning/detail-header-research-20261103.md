# 상세 머리 "기업 요약"과 [다시 조사] (PM 지시 2026-11-03)

**상태**: PM 지시로 약속 파일(계약 요약 v2, 더하는 변경만)에 반영. 코드는 #209·#210·#219.

## 0. 한 줄 결론

회사 자세히 보기 맨 위에 **홈페이지 링크·대표번호·거리·한 줄 소개·주요 특징 3개·마지막 조사 날짜**를 한눈에 보이고, [다시 조사] 단추로 담당자가 원할 때 AI 조사를 다시 돌린다. **주기 자동 조사는 두지 않는다.** 대신 조사가 오래되면(기본 90일) "오래됨" 표시로 알린다.

## 1. 화면 모양 (상세 › 머리)

```
코파스 주식회사                                  [다시 조사]  조사 2026-11-05 (3일 전)
충청남도 아산시 음봉면 월산로 274-1 · 거산에서 12.3km   [네이버 지도] [카카오맵]
홈페이지 kofas.com ↗   대표 041-000-0000
한 줄: 볼트·너트 표면처리 전문, 철계 소재 중심
특징: · 볼트·너트마다 도금 종류 선택 가능  · 원재료 SCM435·S45C  · 니켈·흑착 중심 설명
```

- 거리는 거리 기능(#222) 전까지 빈칸. 대표번호는 공개 자료에 있을 때만.
- 조사 전(사례 파일만 있는 18곳): 한 줄은 사례 파일 `cardReason`, 특징은 비움, 날짜는 투입일에 "사례 파일 기준".
- 90일 넘으면 날짜 옆에 "오래됨" 표시(설정 `research.staleAfterDays`).

## 2. [다시 조사] 동작

1. 확정된 홈페이지 주소가 있으면 기존 흐름 ①(`POST /homepage`, 60초 한도)을 그대로 다시 돌린다: 본문 읽기 → 전송 보호 → OpenAI → 근거·한 줄·특징·대표번호 갱신 → 재평가 → `researchedAt` 갱신.
2. 주소가 없으면 "홈페이지 찾기"(#218)로 안내.
3. 누르기 전에 인라인 한 줄: "지금 조사하면 근거가 새로 뽑히고 다시 평가됩니다 · 이번 달 123/1,000회". 모달 없음.
4. 비용·호출 상한(C4)이 그대로 적용되고, 넘으면 "이번 달 한도 초과"로 거부.

## 3. 왜 단추(수동)인가 — 주기 자동 조사와 비교

| | 단추(추천) | 주기 자동(예: 매월) |
|---|---|---|
| 비용 | 누른 만큼만. 월 $20·1,000회 안에서 예측 가능 | 후보가 50곳이 되면 매달 50회 이상이 고정으로 나가고, 아무도 안 보는 조사에 돈이 든다 |
| 순위 변동 | 담당자가 알고 누른 뒤 바뀜 | 담당자 모르게 밤사이 순위·분류가 바뀜. "어제 2위가 왜 5위?"가 생김 |
| 사람 판단 | 홈페이지 확정·결과 확인을 그 자리에서 | 홈페이지가 바뀐 회사는 자동으로 못 따라감 |
| 상대 사이트 | 필요할 때 한 번 | 반복 접근은 robots·예의 문제 |
| 구현 | 기존 경로 재사용, 약 4h | 스케줄러·실패 알림·배포 환경 작업 추가, 약 12h |

"오래됨" 표시 + 2차 보강에서 대시보드에 "조사 90일 지난 기업 N곳" 건수를 더하면 주기 조사 없이도 빠뜨리지 않는다.

## 4. 약속 파일(더하는 변경, 반영 완료)

- C1 상세 `header`: `address`, `distanceKm`(null 가능), `summaryLine`, `highlights[≤3]`, `researchedAt`, `researchSource: AI|CASE_FILE`, `researchStale`
- C1 `POST /homepage`: [다시 조사]가 같은 경로, 성공 시 머리 칸 갱신
- C6 `opp_customer`: `summaryLine`, `highlights`, `researchedAt`, `researchSource` 열(더하는 마이그레이션)
- C7: `research: { staleAfterDays: 90 }`
- C9 LlmAdapter 결과: `companySummary { line, highlights }`, `companyMainPhone`
