## Q1. React 화면 부품 라이브러리는 무엇을 씁니까? (러프 화면 Q4에서 "비전공 팀이 쓰기 쉬운 것으로 추천" 요청)

기준: 비전공 4인 팀이 AI 도구로 쓰기 쉬울 것, 깔끔한 업무용 화면, 표·카드·탭·태그·폼 부품이 바로 있을 것, 한글 자료가 많을 것, 강조색 1개와 로고를 한 곳에서 바꿀 수 있을 것.

A. Ant Design 5 — 업무용 표·폼·태그·탭·서랍 부품이 가장 완비되어 있고 한국 업무 시스템에서 널리 쓰여 예제가 많음. 테마 토큰으로 강조색 1개 교체 쉬움 (추천)
B. MUI(Material UI) 6 — 가장 널리 쓰이는 범용 라이브러리. 구글 Material 느낌이 강해 "깔끔한 업무용"으로 맞추려면 손질이 더 필요
C. shadcn/ui + Tailwind — 가볍고 세련되지만 부품을 직접 조립해야 해 비전공 팀에 부담
D. Chakra UI — 접근성 기본값이 좋고 단순하지만 표·복합 폼 부품이 적음
X. Other (please specify)

[Answer]: X. Other — A를 기본으로 한다: Ant Design 5. 일정이 빠듯하므로 기본 부품을 그대로 쓰되, 처음부터 테마 설정으로 세련된 업무용 느낌을 낸다: 강조색 1개 + 회색 계열, 읽기 좋은 한글 글꼴, 넉넉한 여백, 살짝 둥근 모서리. 빽빽한 ERP 느낌은 피한다(거산이 이전 시안을 ERP 같다고 했다). 세부 디자인 다듬기는 P3. 진행 단계 표시는 Ant Design의 Steps 부품을 쓴다.
