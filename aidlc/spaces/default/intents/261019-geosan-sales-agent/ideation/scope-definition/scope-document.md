# 범위 문서 (Scope Document) — 거산케미칼 AI 영업지원 에이전트 2차

이 문서는 첫 버전(2차)에서 "무엇을 만들고, 무엇을 만들지 않으며, 어떤 순서와 일정으로 가는지"를 확정한 기준입니다. 의도 문서(`../intent-capture/intent-statement.md`)의 문제·성공 기준·제외 범위, 실현 가능성 평가서(`../feasibility/feasibility-assessment.md`)의 P0~P3 초안과 판정, 제약 목록(`../feasibility/constraint-register.md`)의 제약 23개를 받아, `scope-definition-questions.md`의 확인된 답변(Q1~Q8)으로 확정했습니다.

## 1. 한 장 요약

| 항목 | 확정 내용 |
|---|---|
| 핵심 가치 | 거산의 공정 9종 역량과 인증 조건을 고객 영업기회와 대조해, 추천 이유·확인 질문·다음 행동을 영업 담당자에게 보여주는 웹 도구 (의도 문서) |
| 첫 버전의 끝 | 11/15까지 P0 + P1 완료, 거산이 접속해 실사용 가능. P2는 11/27 통합 인수까지, P3은 여유 시 |
| 10/30 초기 동작 | 가상 사례 1건(A정밀)이 필터 → 점수 → 분류 → 추천 목록·근거 상세 → 담당자 의견 저장까지 한 번에 이어짐 (Q2) |
| 만드는 순서 | 가상 사례 1건이 입력부터 화면까지 끝까지 통과하는 "뼈대"를 먼저, 그다음 의존 순서로 살을 붙임 (Q6) |
| 가상 사례 | A정밀 아노다이징(계산 검증용, 기획서 수치 그대로) + 아연도금 신규 기회(거산 시연용, 부록 F로 새로 계산, 가상 표시) (Q1 추가) |
| 기업 피드백 | G0 면담(10/27 목표)에서 시연, 10/30 이후 메일로 리스트·근거 전달 후 서면 의견 (Q3) |

## 2. 범위 안 (In Scope)

실현 가능성 평가서의 P0~P3 초안을 그대로 확정했습니다 (Q1). P1에 아연도금 가상 사례를 추가했습니다.

### P0 — 반드시 (11/6 첫 흐름 완성 목표, 10/30 초기 동작)

| 번호 | 내용 | 비고 |
|---|---|---|
| P0-1 | 9종 공정 구조와 가상 검수 데이터 (공정·사양·인증·검수 상태) | 거산 실제 값은 검수 전이므로 가상 표시 |
| P0-2 | 고객·영업기회 기록과 같은 기회 병합 (발견 경로가 달라도 기회 ID 하나) | 상호명·주소 기반 병합, 불확실하면 사람이 확인 |
| P0-3 | 공통 평가: 필수조건 필터 → 점수(부록 F) → 분류(11개 분기) → 정렬 | 규칙 수치는 바꾸지 않음. 세부 미정 규칙은 요구사항 단계에서 질문 |
| P0-4 | 근거 추출: 홈페이지 URL이나 본문이 주어지면 제품·소재·처리 목적 근거와 확인 질문을 자동 추출 (외부 LLM, 공개 자료만). URL이면 본문(연락처 제외) 자동 수집, robots.txt·이용약관 준수 (Q5) | 연락처 자동 수집 금지 |
| P0-5 | 화면 3개: 추천 목록, 근거 상세, 의견/결과 | 꾸밈은 최소 |
| P0-6 | 신규 기회 흐름이 끝까지 이어짐: 후보 → 근거 → 평가 → 추천 → 담당자 의견 저장 | 10/30 초기 동작의 정의 (Q2) |
| P0-7 | 산단공 전국등록공장현황 CSV에서 실제 후보 불러오기 | 10/30에는 "가능하면", 늦어도 11/6까지 (Q2) |

### P1 — 11/15까지

| 번호 | 내용 | 비고 |
|---|---|---|
| P1-1 | 재접촉 흐름: 담당자 최소 필드 입력 → 재접촉 프로필 계산 → 이력·재접촉 이유·후속 일정 표시 | 가상 사례로 구현·검증. 외부 LLM 호출 없음 (Q7 조건부) |
| P1-2 | 승인·접촉 시도·영업 결과의 최소 기록 (시스템 분류·담당자 의견·결과를 따로 저장) | |
| P1-3 | 외부 소스 추가 연결: 공장등록생산정보 API(업종코드 보강), 특정수질유해물질 업체 CSV(제외 명단) 중 1~2개 | 이용·저장 허용 범위 확인 후 |
| P1-4 | 아연도금 신규 기회 가상 사례 1건: 기대 결과를 부록 F 규칙으로 새로 계산, "거산 실제 사양 아님·가상" 표시 | 거산 시연용. 2회차 기업 미팅 주제 (Q1 추가) |
| P1-5 | 홈페이지 자동 탐색: 회사명+주소로 홈페이지를 찾고, 확신이 낮거나 못 찾으면 "확인 필요"로 표시해 담당자가 URL 입력·확정 | 검색 방식의 비용·약관 확인 필요 (Q5) |
| P1-6 | 거산이 접속해 써 볼 수 있는 실행 환경 준비 | 방식은 G0와 인프라 설계에서 결정. 저비용·쉬운 설정 우선 |

### P2 — 11/27 통합 인수까지

| 번호 | 내용 |
|---|---|
| P2-1 | 엑셀·단순 PDF 출력 (화면과 같은 상태·근거) |
| P2-2 | 나머지 외부 소스 연결 (나라장터 입찰공고 API 등 3개 소스 완성) |
| P2-3 | 추가조사 분류 기회의 질문·경로·담당·시간·재확인일 기록 |

### P3 — 여유가 있을 때

| 번호 | 내용 |
|---|---|
| P3-1 | 수동 명단 활용: 뿌리기술 전문기업 명단(경쟁사 제외), 방산업체 지정현황(방산 공급망 씨앗). 한 번 내려받는 명단이며 자동 소스가 아님 (Q4) |

## 3. 범위 밖 (Out of Scope)

| 구분 | 항목 | 근거 |
|---|---|---|

| 이번에 확정한 제외 (후속 확장 후보) | RFQ·도면 자동 구조화, 가중치 자동 조정, 예측모델 학습, CRM·ERP·메일 연동, 설비 가동능력 판단, 전용 조사 관리 화면, 기업 독립 수집·규칙 관리 화면 | Q7 |
| 조건부 제외 | 재접촉용 로컬 모델: 거산이 고객명 포함 AI 문안을 원하면서 외부 전송을 거부하거나, 재접촉 보안 문제로 필요할 때 G0 이후 검토 | Q7 |

| 소스 제한 | 채용 공고 사이트(약관 문제, 공공 API 확인 시 재검토), 유료 기업 DB, 홈페이지 연락처 자동 수집 | Q5, 제약 목록 |
| 판단 보류 | 1차 MVP 기능(회사소개서 생성) 재구현 또는 1차 통합: 11/13 중간 점검에서 결정, P0·P1 완료 시에만 검토 대상 | Q8 |

## 6. 지연 시 줄이는 순서

실현 가능성 평가서의 판정대로 "11/15까지 P0 + P1"도 빠듯합니다. 늦어지면 다음 순서로 줄입니다. 필수 판정(필터)을 생략하거나 점수로 우회하는 조정은 하지 않습니다.

1. P3 전부, 화면 꾸밈
2. P2 출력·나머지 소스 (엑셀만 남기고 PDF 제외 가능)
3. P1-5 홈페이지 자동 탐색 (URL 수동 입력으로 대체)
4. P1-3 소스 추가 연결 (CSV 1개로 유지)
5. P1-1 재접촉 흐름을 "가상 사례 기본 동작"까지만
