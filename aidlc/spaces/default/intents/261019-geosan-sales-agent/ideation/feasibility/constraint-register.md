# 제약 목록 (Constraint Register) — 거산케미칼 AI 영업지원 에이전트 2차

이 목록은 의도 문서(`../intent-capture/intent-statement.md`)의 범위 신호와 `feasibility-questions.md`의 확인된 답변에서 뽑은, 설계·구현 내내 지켜야 할 제약입니다. "상태"는 확정 / 확인 필요 / 미정 중 하나입니다.

## 기술 제약

| ID | 제약 | 출처 | 영향 | 상태 |
|---|---|---|---|---|
| CON-01 | 기술 기본안은 Python, FastAPI + React, SQLAlchemy, 개발 DB SQLite로 확정 | Q5 | 다른 언어·프레임워크를 새로 도입하지 않음 | 확정 |
| CON-02 | 구조는 최대한 단순하게. 처음 보는 기술·복잡한 인프라(메시지 큐, 여러 서비스로 나누기, 복잡한 클라우드 구성)는 피함 | Q5 | 설계 단계에서 단일 애플리케이션·단일 DB를 기본으로 검토 | 확정 |
| CON-03 | 실행 중인 외부 시스템과의 연동 없음. 1차 MVP 코드는 참고·일부 재사용만 가능 | Q1 | 연동 API·동기화 설계 불필요 | 확정 |
| CON-04 | 자동 수집 소스는 3개: 산단공 공장현황 CSV + 공장등록생산정보 API, 특정수질유해물질 업체정보 CSV, 나라장터 입찰공고 API | Q10 | 수집 기능은 이 3개에 맞춰 설계 | 확정 (허용 범위는 확인 필요) |
| CON-05 | 산단공 공장현황 CSV에는 사업자등록번호가 없음 → 상호명·주소로 기업 병합 | Q10, 리서치 문서 | 기업 식별 규칙 필요, 불확실한 병합은 사람이 확인 | 확정 |
| CON-06 | 공장등록생산정보 API 개발 계정은 하루 1,000건 제한 | 리서치 문서 | 대량 보강은 나눠서 실행하거나 운영 계정 신청 | 확인 필요 |
| CON-07 | 기업 홈페이지·보도자료는 후보별 제품·소재 근거 확인용으로만 사용. 이메일·전화 등 연락처는 자동 수집하지 않음 | Q10 | 홈페이지 자동 크롤링으로 연락처를 긁는 기능 금지 | 확정 |
| CON-08 | 채용 사이트와 유료 기업 DB는 이번에 쓰지 않음 | Q10 | 해당 소스 연결 기능 없음 | 확정 (추가 활용 여부는 미정) |
