# RAID 기록 (위험·가정·이슈·의존) — 거산케미칼 AI 영업지원 에이전트 2차

RAID는 위험(Risk), 가정(Assumption), 이슈(Issue), 의존(Dependency)의 머리글자입니다. 의도 문서(`../intent-capture/intent-statement.md`)와 `feasibility-questions.md`의 확인된 답변을 바탕으로 적었습니다. 가능성·영향은 팀의 초기 판단이며 진행하면서 갱신합니다.
