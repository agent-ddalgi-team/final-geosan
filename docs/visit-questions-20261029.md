# 10/29 거산 방문 때 확인할 질문 목록 (역량 파일 기준)

소개서 묶음 역량 파일 `examples/capability-geosan-brochure.json`에서 `UNKNOWN`·`UNCONFIRMED`로 두었거나 값을 비운 항목입니다. 답을 받으면 PM이 파일을 고치고(`basis`·`reason`의 "다음 할 일"대로) 검수 상태를 바꿉니다. 근거 위치는 모두 `docs/input/04_거산회사소개서.md`(2026-09-21판)입니다. 이슈 #17, 안내서 `docs/case-file-guide.md` 5-1장.

## A. 꼭 물어볼 것 (답에 따라 평가 결과가 달라짐)

| A2 | **한화시스템 특수공정 승인서**의 선명한 원본(스캔본)과 **현재 유효한 갱신본**을 받을 수 있습니까? 승인번호·지침 번호·유효기간을 읽고 싶습니다. | 이미지가 흐려 번호·유효기간 판독 불가, 보이는 기간(2020.02~2021.02)은 지났을 가능성 (8장 '한화시스템 특수공정 승인서 상세') | 번호·기간 채우고 상태 `ACTIVE` 또는 `EXPIRED` |
| A3 | 그 승인서의 **승인 공정 목록**은 무엇입니까? 연혁에는 2019년 아연·아노다이징·무전해니켈, 2020년 크로메이트·부동태로 나뉘어 있습니다. | 승인서 본문은 '도금'뿐, 공정별 승인은 연혁에만 (4장 연혁) | 다섯 공정의 범위를 `APPLIES`/`NOT_APPLIES`로 |
| A4 | **휴니드테크놀러지스 특수공정 인증(2017)** 과 **세트렉아이 승인(2020)** 은 지금도 유효합니까? 어느 공정이고 인증서 번호·유효기간은 무엇입니까? | 연혁과 거래처 표에만 한 줄씩 있고 증서 내용이 없음 (4장·12장) | 유효하면 `ACTIVE` + 공정 범위 추가, 아니면 `EXPIRED` |

| B3 | 아노다이징은 **알루미늄 주물(다이캐스팅)** 도 처리합니까? 처리 가능 소재 목록(Al·Mg·Zn·Ti·Hf·Nb)에 주물을 넣어도 됩니까? | 소재 표에 주물이 따로 없음 (10장 02). 실제 사례 파일의 `appliedMaterial`에 영향 | `materialCodes`에 `AL_CASTING` 추가 여부 |

| B6 | 주요 거래처(방위산업·반도체/자동차)마다 **어느 공정으로 무엇을** 납품했습니까? 공개 자료(소개서·홈페이지)에 적어도 되는 범위로 알려 주세요. | 거래처는 산업별로만, 공정·부품은 없음 (12장) | `deliveryRecords`의 `partType`·`period`·공정 배치 수정 |
| B7 | KSPC 인증(KSPC-2026-0012, 범위 'KSPC510 화학처리-CP')이 크로메이트·아노다이징·부동태 세 공정을 뜻하는 것이 맞습니까? | 범위 코드만 있고 공정 이름은 연혁에서 추정 (8장·4장) | 맞으면 그대로, 아니면 범위 수정 |

## D. 추천 순위·화면 표시에 대해 물어볼 것 (답에 따라 설정 파일 값이 바뀜)

| 번호 | 질문 | 왜 묻나 | 답을 받으면 |
|---|---|---|---|
| D1 | 아직 접촉 후보가 아닌 기업들(기다리는 중·확인 필요)을 줄 세울 때, **공개 자료로 실제 확인된 점수(E, 100점 만점)** 순이 맞습니까, 아니면 화면에 보이는 **"참고 N"(판정한 배점 중 확인된 비율, S = E ÷ P × 100)** 순이 맞습니까? 예: 명화금속은 확인 50점·판정 55점이라 "참고 91"이고, 동화경금속은 확인 50점·판정 100점이라 "참고 50"인데 지금은 둘 다 확인 50점이라 나란히 1·2위입니다. | 지금 규칙(BR6.5, 가설·설정값)은 소개서 묶음일 때 E 내림차순 → R 내림차순이고, 화면에는 S("참고 N")가 보여 "왜 91이 50 아래에 있나"로 보일 수 있음. 기획서 부록 F에 없는 화면용 규칙이라 거산 판단이 필요 | E 순이면 그대로. S 순이면 `examples/rule-config.yaml`의 `otherGroupSort.brochure`만 바꾼다(코드 수정 없음). 어느 쪽이든 화면 카드에 "확인 점수"도 함께 보일지 결정 |
| D1-덧붙임 | (시연 때 설명할 것) "참고 N"은 **판정한 항목 수에 따라 크게 달라집니다.** 8항목을 끝까지 판정해 '없음(0점)'으로 적은 회사는 분모가 100이 되어 참고 50, 다섯 항목을 비워 둔 회사는 분모가 55가 되어 참고 91이 됩니다(확인된 점수는 둘 다 50). 시연 자료에는 "확인된 점수 50 / 판정한 배점 55"처럼 두 숫자를 함께 보여 오해를 막습니다. | 참고 점수만 보면 "조사를 덜 한 회사가 더 좋아 보이는" 역전이 생김(2026-10-24 1차 출력에서 확인) | 거산이 "참고 비율"을 계속 쓰길 원하면 11월 규칙 정리 때 분모를 "100점 전체"로 바꿀지(미확보도 0으로 셈) 설정 변경 후보로 올림 |
| D2 | 추천 목록의 8항목 중 **"미확보"**(예: 상대 회사의 최근 증설·채용·신규 수주)는 지금은 담당자가 공개 자료를 직접 찾아보거나, 전화로 알게 된 내용을 파일로 고쳐 다시 넣어야 점수에 반영됩니다. 거산 담당자가 실제로 쓸 때 **"확인한 사실을 화면에서 직접 입력해 다시 평가"**하는 기능이 필요합니까? 필요하면 어느 정도까지(간단 입력 / 자료 첨부 후 자동 기입)? | 지금 설계는 자동 추출(U2, 홈페이지 본문)과 접촉 결과 기록(U5)만 있고, 상대 회사의 시점 신호를 사람이 직접 넣는 칸은 어느 단위에도 없음. 11/15 실사용 전에 범위에 넣을지 정해야 함 | 필요하면 범위 변경(P1~P2)으로 백로그에 올리고 PM이 우선순위 결정. 후속 확장 안은 #63 "정할 것" 참고(질문창에 파일·텍스트 첨부 → 에이전트가 항목 값 제안 → 기입자·일시 기록 → 담당자가 "정말 넣겠습니까" 확인 뒤 저장·재평가) |
