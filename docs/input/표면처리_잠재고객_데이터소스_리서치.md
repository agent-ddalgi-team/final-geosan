# 금속 표면처리 업체 잠재고객 발굴용 국내 공개 데이터 소스 리서치

**작성일:** 2026-08-28
**의뢰사:** 금속 표면처리 전문업체 (아연도금 / 아노다이징 / 무전해니켈 / 크롬도금 / 전해연마 / 알칼리흑착 / 인산염피막 / 크로메이트 / 부동태)
**확인 방법:** 아래 기재한 각 URL에 이 문서 작성 시점에 **실제로 HTTP 접속을 시도**했다. 접속 결과를 다음 3단계로 표기한다.

| 표기 | 의미 |
|---|---|
| ✅ **확인됨** | 접속 성공 + 페이지 내용에서 해당 사실을 직접 읽어냄 |
| ⚠️ **부분확인** | 도메인/URL은 살아 있으나 JS 렌더링·인증서 오류 등으로 내부 내용을 못 읽음. 존재만 확인 |
| ❌ **검증 필요** | 접속 실패, 또는 2차 출처(검색 요약·블로그·기사)로만 파악. **존재·사양을 단정하지 않음** |

> **중요 한계 고지**: 한국 공공기관 사이트 상당수가 JS 기반 SPA라 HTTP 페치만으로는 본문이 비어 온다. 그런 경우 "사이트가 없다"는 뜻이 **아니다**. 아래에서 ⚠️/❌로 구분해 두었으니, 실사(實査) 단계에서 브라우저로 직접 열어 재확인해야 한다.
> 수치는 **출처 URL 또는 계산 과정**이 붙은 것만 기재했다. 근거 없는 추정치는 쓰지 않았다.

### 3-2. 사업자등록번호 정규화

```
1. 하이픈·공백·괄호 제거  →  "123-45-67890" → "1234567890"
2. 좌측 0 손실 복구  →  엑셀 수치화로 앞자리 0이 날아간 값을 zfill(10)
3. 체크섬 검증 (국세청 사업자번호 검증식)
   가중치 [1,3,7,1,3,7,1,3,5]를 앞 9자리에 곱해 합산,
   9번째 자리(index 8)에는 값×5 의 십의자리+일의자리를 더함,
   (10 - 합계 % 10) % 10 == 10번째 자리  이면 유효
4. 유효 번호에 대해 국세청 상태조회 API로 폐업/휴업 제거
   → https://www.data.go.kr/data/15081808/openapi.do (월 100만건 무료 ✅)
```
※ 체크섬 알고리즘 자체는 널리 알려진 공식이나 **본 조사에서 국세청 1차 출처로 확인하지 못했다** ❌ **검증 필요**. 실무에서는 체크섬 대신 **국세청 API 상태조회 응답**을 유효성 판정에 쓰는 것이 안전하다(1차 출처 기반).

## 4. "도금 내재화 여부"를 외부 데이터만으로 판별하는 방법

※ 아래 정확도 수치는 **본 조사에서 실측한 것이 아니다.** 신호의 성격에 근거한 **상대적 순위 판단**이며, 실제 값은 샘플 100개사 수작업 검증으로 캘리브레이션해야 한다 ❌ **검증 필요**.

### 신호 1 — KSIC 업종코드 (11차 기준) ★★★

**실제 확인한 코드 (indicode.kr 표준산업분류 해설서, 11차 기준 ✅ 접속 확인 — 단 indicode.kr은 민간 사이트이므로 2차 출처. 통계청 원문 대조 ❌ 검증 필요)**

- 시스템: https://icis.mcee.go.kr/ ⚠️ (접속 성공, 내용 미확인)
- **물질명 단위**로 판별: 크롬 및 그 화합물 / 시안화합물 / 니켈 및 그 화합물 / 질산 / 황산 / 불화수소
- **정확도**: 신호 2보다 정밀(물질 특정 가능). **한계**: 조사대상 사업장 규모 기준(종업원 수·취급량 하한)이 있어 소규모 누락. 실제 공개 범위·API 제공 여부 ❌ **검증 필요**

### 신호 4 — 홈페이지 텍스트 신호 ★★

**긍정(=내재화, 배제) 키워드 — 설비/공정 페이지에서 탐지**
```
설비 목록:  도금조 / 정류기 / 자동도금라인 / 랙(rack)도금 / 바렐(barrel)도금 /
           배럴도금 / 전해조 / 양극산화조 / 폐수처리장 / 스크러버 /
           탈지조 / 산세조 / 크로메이트조 / 봉공처리
공정 소개:  아연도금 / 삼가크로메이트 / 아노다이징 / 경질알루마이트 /
           무전해니켈 / 카티온전착 / 전해연마 / 흑색산화피막
자격:      도금기능사 / 표면처리기술사 / 표면처리산업기사
```
**부정(=외주, 타깃) 키워드**
```
"표면처리는 협력업체를 통해", "후처리 외주", "도금 협력사",
"당사는 정밀가공 전문", 설비목록에 CNC/MCT/프레스/용접만 있고 도금조 없음
```
**정확도**: 중. **한계 4가지**
1. **중소 가공업체는 홈페이지가 없거나 갱신이 5년 이상 멈춰 있다** → 커버리지가 가장 큰 문제. 산단공 217,048개 중 홈페이지 보유 비율은 미지수 ❌
2. **"도금"을 서비스 소개에 적어놨지만 실제론 외주**인 경우(영업상 자사 역량처럼 표기)
3. 반대로 도금라인이 있어도 **홈페이지에 안 적는 업체**가 많다
4. **크롤링 시 로봇배제표준·약관 확인 필수**

### 신호 5 — ISO/KS 인증서의 **인증범위(scope) 문구** ★★★ (가장 정확하지만 수집이 어려움)

**판별 논리**: ISO 9001 인증서의 `Scope of Certification` 문구는 **인증기관이 실사로 확인한 실제 공정 범위**다. 자기신고인 KSIC보다 훨씬 신뢰도가 높다.
```
배제 문구 예:  "…의 표면처리(도금)"  "Manufacture and Plating of…"
              "Surface Treatment"  "Electroplating"  "Anodizing"
타깃 문구 예:  "…의 정밀가공 및 조립"  "Machining and Assembly of…"
              (표면처리/도금 단어가 scope에 없음)
```
**정확도**: 매우 높음. **한계 3가지**
1. **수집 경로가 막혀 있다.** 인정기관(KAB ⚠️)이 인증서 scope를 전수 공개하지 않는다. 개별 인증기관 사이트를 건별로 조회해야 하고, scope 전문을 노출하지 않는 곳도 많다 ❌ **검증 필요**
2. scope 문구가 축약형("금속제품 제조")이면 판별 불가
3. **항공 계열은 예외적으로 유리하다** — AS9100/EN9100/KS Q 9100은 **IAQG OASIS**에 등재되며 scope가 함께 실린다. 다만 OASIS는 **HTTP 403** ❌ 접근 방법 검증 필요

### 신호 6 — 채용공고 직무명 ★★

- 소스: 잡코리아 / 사람인 / 워크넷 ❌ **모두 미접속, 검증 필요**
```
내재화 신호 직무:  도금 오퍼레이터 / 도금 반장 / 표면처리 생산직 /
                  폐수처리 담당 / 환경안전(수질) 담당 / 도금 품질검사
외주 신호:        가공(CNC/MCT) / 조립 / 용접 / 프레스 만 반복 채용
```
**정확도**: 중~상. **한계**
1. **채용을 안 하는 시기엔 신호가 안 잡힌다** — 시계열로 1~2년 누적해야 유의미
2. **채용사이트 크롤링은 대부분 약관 위반**이다 ❌ 반드시 각 사이트 이용약관 확인. 워크넷(고용노동부)은 공공데이터포털 API 제공 가능성 있음 ❌ **검증 필요**
3. 파견/도급 인력을 쓰면 직접 채용 공고가 안 뜬다

### 신호 7 — 공장등록 정보(생산품 자유텍스트) ★★

- 소스: 산단공 전국등록공장현황의 **`생산품`** 필드 ✅ (217,048행 전체에 존재)
- `생산품` 값에 "도금", "아연도금", "아노다이징", "표면처리", "피막", "코팅"이 들어가면 → 배제 후보
- **정확도**: 중. **한계**: 자유 입력이라 표기 흔들림이 심하고("도금", "메끼", "메키", "plating"), 최종 제품명만 적고 공정은 안 적는 경우가 대다수

### 신호 8 — 특허 출원 IPC/CPC 분류 ★

- 소스: KIPRIS ⚠️ / KIPRIS Plus API ⚠️ ❌ **검증 필요**
- **C25D**(전기분해·전기영동에 의한 피복), **C23C**(금속재료 피복법), **C23G**(금속재료의 세정·산세) 출원 이력 → 도금 기술 보유
- **정확도**: 높으나 **재현율이 매우 낮다**. 도금라인을 돌려도 특허를 안 내는 중소업체가 절대다수 → **보조 신호로만**

### 8개 신호의 종합 판정 설계

```
배제 점수 = 3×(신호2 히트) + 3×(신호3 히트) + 3×(신호5 히트)
          + 2×(신호1: KSIC 25922/25923)
          + 2×(신호4 긍정키워드) + 2×(신호6 도금직무)
          + 1×(신호7 생산품) + 1×(신호8 C25D/C23C)

점수 ≥ 3  → 내재화 확정, 타깃에서 제외
점수 1~2  → 보류. 영업 1차 통화로 확인 (전화가 가장 싸고 빠른 검증 수단)
점수 0    → 외주 후보. 신호 4의 '부정 키워드'가 있으면 우선순위 상향
```
**중요**: 어떤 단일 신호도 단독으로 쓰면 안 된다. **신호 2(폐수)와 신호 5(인증 scope)가 가장 강하지만 둘 다 위음성(누락)이 크다**. 그래서 가중합 + 보류 구간을 두고 **보류는 전화로 푼다.** 데이터로 100% 판별하려고 애쓰는 것보다 그게 싸다.

### 5-1. 제50조 (영리목적의 광고성 정보 전송 제한) — law.go.kr 확인 내용 ⚠️

| 항 | 확인된 내용 |
|---|---|
| **제1항** | 누구든지 **전자적 전송매체**를 이용하여 영리목적의 광고성 정보를 전송하려면 수신자의 **명시적인 사전 동의**를 받아야 한다. **예외 있음** ✅ |
| **제1항 예외(확인됨)** | ① 재화 등의 **거래관계를 통하여 수신자로부터 직접 연락처를 수집**한 자가 **대통령령으로 정한 기간 내**에 **자신이 취급하는 동종의 재화** 광고를 전송하는 경우 ✅ / ② 「방문판매 등에 관한 법률」에 따른 **전화권유판매자가 육성으로** 수신자에게 **개인정보 수집출처를 고지**하고 전화권유를 하는 경우 ✅ |
| **제2항** | 수신거부 의사표시 또는 사전동의 철회 후에는 전송 금지 ✅ |
| **제3항** | **오후 9시 ~ 다음날 오전 8시** 전송 시 **별도의 사전 동의** 필요. 대통령령이 정한 매체는 예외 ✅ |
| **제4항** | 전송자의 **명칭 및 연락처**, **수신거부·동의철회를 쉽게 할 수 있는 조치**에 관한 사항 등을 **명시**해야 함 ✅ |
| **제5항** | 5가지 금지행위: 수신거부 회피·방해 조치, **자동으로 연락처를 생성하는 조치**, 신원·전송출처 은폐 조치, 기망하여 회신을 유도하는 조치 등 ✅ |
| **제6~8항** | 수신거부 비용을 수신자에게 부담시키지 않을 의무, **처리결과 통지** 의무, **정기적 수신동의 확인** 의무 ✅ |

**핵심 해석**
- **"전자적 전송매체"**가 규제 대상이다 → **이메일, 문자(SMS/MMS), 팩스, 메신저, 자동 음성 전화(ARS)** 포함
- **육성(사람이 직접 말하는) 전화**는 제1항 단서 ②에 의해 **전화권유판매자 요건을 갖추면 사전동의 없이 가능** ✅ ← **이것이 B2B 콜드콜의 법적 근거**
- **우편(종이 DM)**은 "전자적 전송매체"가 아니다 → **제50조 적용 대상이 아니다** (단 개인정보보호법은 별개)

### 5-2. 제50조의2 (전자우편주소의 무단 수집행위 등 금지) — 2차 출처 기반 ❌

2차 출처(다수 공공기관 '이메일무단수집거부' 고지 페이지에서 반복 인용되는 문구)상 3개 항으로 구성된다:
1. **인터넷 홈페이지 운영자·관리자의 사전 동의 없이**, 홈페이지에서 **자동으로 전자우편주소를 수집하는 프로그램 그 밖의 기술적 장치**를 이용하여 전자우편주소를 수집하는 행위 금지
2. 제1항을 위반하여 수집된 전자우편주소의 **판매·유통** 금지
3. 수집·판매·유통이 금지된 주소임을 **알면서 정보전송에 이용**하는 행위 금지

**→ 실무상 가장 중요한 해석 (본 리서치의 핵심 판단)**

| 행위 | 제50조의2 저촉 여부 |
|---|---|
| 홈페이지를 **사람이 직접 열람**하고 담당자 이메일을 **손으로 옮겨 적음** | **저촉되지 않는다.** 조문이 금지하는 것은 "**자동으로 수집하는 프로그램·기술적 장치**"의 사용이다 |
| **크롤러/스크래퍼를 돌려** 홈페이지에서 이메일을 **자동 수집** | **저촉된다.** 홈페이지 운영자의 사전 동의가 없으면 위법. **"공개되어 있으니 괜찮다"는 논리는 통하지 않는다** |
| 수집한 이메일 리스트를 **구매**해서 사용 | 제2·3항 저촉. 출처가 자동수집이면 **알고 썼다**는 점이 문제됨 |
| 대부분의 한국 기업 홈페이지 하단 **"이메일무단수집거부"** 고지 | 이 고지 자체가 **제50조의2의 사전 동의를 명시적으로 거부한 것** → 자동수집 시 고의 입증이 쉬워진다 |

**결론: 이메일 채널은 자동수집 경로를 원천 차단하고, ① 수동 수집 + ② 명시적 사전 동의 확보 두 단계를 모두 거쳐야 쓸 수 있다.** 그런데 ②의 사전 동의를 받으려면 먼저 컨택해야 하므로, **첫 접촉을 이메일로 하는 것은 구조적으로 위험하다.**

### 5-3. 채널별 종합 판정

| 채널 | 근거 조문 | 판정 | 실무 요건 |
|---|---|---|---|
| **육성 전화 영업** | 정보통신망법 §50①단서 ② (방문판매법상 전화권유판매자) ✅ | ✅ **가장 안전. 1순위 채널** | ① 방문판매법상 **전화권유판매업 신고** 필요 여부 확인 ❌ **검증 필요** ② 통화 시작 시 **개인정보 수집 출처를 고지**해야 함 ✅ ③ 자동 발신(ARS/봇)은 안 됨 — **육성**이어야 함 ④ 「표시·광고의 공정화에 관한 법률」상 **거짓·과장 광고 금지** 적용 ❌ 조문 미확인 |
| **우편 DM** | §50의 "전자적 전송매체"에 해당하지 않음 ✅ | ✅ **안전. 2순위 채널** | 법인 주소는 개인정보가 아니다. 다만 **수취인을 개인명("○○○ 팀장님")으로 특정하면 개인정보 처리**가 되어 개인정보보호법 적용 ❌ **검증 필요** → **"구매팀 담당자 앞"처럼 직책 수신**으로 보내면 리스크가 낮다 |
