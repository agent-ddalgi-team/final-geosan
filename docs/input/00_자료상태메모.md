## 4. 확실한 것 / 아직 정해지지 않은 것

### 확실한 것

- 기술 기본안: Python, FastAPI + React, SQLAlchemy, 개발 DB는 SQLite
- 점수는 규칙 엔진(결정적 계산)이 내고, LLM은 근거 추출·질문 생성·문안 초안 3곳에만 씁니다.
- 재접촉 흐름은 기본값이 "LLM 호출 없음"(고객 이력을 외부 AI에 보내지 않음)
- 실제 데이터가 없어도 **표시된 가상 사례로 기능은 모두 구현·검증**합니다.
- **첫 대응 흐름은 신규 기회로 결정**했습니다.
- 공정 3번: 알카리흑착과 흑착색은 같은 공정입니다.
- 팀 역할: 최지예(PM·설계), 이강욱(백엔드), 고선주(프론트엔드), 유동렬(에이전트/AI). 주간 가용 시간은 미정

- 2차가 잘 만들어지고 시간이 남으면: 1차 MVP를 연결하지 않고, **이 레포 안에서 확장**해 1차의 기능(공정별 고객맞춤 영업자료·회사소개서 생성)을 새로 만듭니다.
- 시간이 부족하면: **이미 만든 1차 MVP의 기능을 가져와 추가**하는 방식으로 대신합니다.

## 6. 기업·멘토링에서 확인한 맥락

### 거산케미칼이 원한 것 (1차 미팅 정리)

거산이 원하는 건 **"영업을 늘려줄 AI"보다 "회사가 가진 기술과 노하우를 자료와 디지털로 정리하는 것"**에 가까움.

#### 대표님이 가장 원하는 것

**① 제대로 된 회사소개서 (가장 분명하게 말한 요구)**
- 10년 전에 정부지원금 천만 원으로 만든 소개서가 있는데 낡아서 1~2년 쓰고 못 쓰고 있음
- 요즘 구매 담당자들은 만나기 전에 "회사소개서 메일로 보내달라"고 하는데, 기술은 있어도 보낼 자료가 없어서 곤란함
- 영업사원이 도면만 들고 말로 설명하는 대신 소개서를 같이 보여주면서 설명하길 원함
- 소개서에 꼭 넣어달라고 한 강점:
  - **빠른 납기**: 다른 업체는 2주~한 달 걸리는데 거산은 1주 이내(월요일 입고, 금요일 출고)
  - **민수와 방산을 둘 다** 하는 업체라는 점, 천안 반도체 지역이라는 틈새시장
  - **꼼꼼한 피드백**: 입고 때 스크래치를 동영상으로 남기고, "백색이면 일반인지 무광인지", 두께는 얼마인지 고객에게 다시 확인해줌
  - 아노다이징 같은 공정을 고객이 알아들을 수 있게 설명 보강
- 상무님은 거산케미칼을 검색했을 때 나오는 **소개 영상이나 웹 소개**도 언급. 지금 홈페이지가 없음

**② 아날로그 업무를 디지털로 전환**
- 작업지시서와 공정관리가 아직 종이와 수작업
- 12월 방산 인증 심사에서 몇 년째 "디지털로 하라"는 말을 듣고 있음. 녹취에는 "KSPC"로 적혀 있으나 음성인식이라 정확한 명칭 확인 필요
- 한꺼번에 다 하는 게 아니라 **공정 하나라도 먼저** 시작하고 싶어 함

**③ 거산 공정에 맞춘 불량 대응 가이드**
- 한 직원이 ChatGPT에 불량 원인을 물었더니 "계면활성제를 넣으라"는 답이 나왔고 그대로 하려고 함. 실제로 계면활성제는 2번 공정(탈지)에 이미 들어 있어 틀린 조언이었음
- 원하는 건 인터넷 일반 지식이 아니라 **거산 공정도를 근거로 "뿌옇게 됐으면 1·2·3번 순서로 점검하라"**는 식의 맞춤 가이드

**④ 단계적으로, 실제로 쓸 수 있게**
- "100을 못 하니 10부터, 그다음 20", "지금은 1부를 쓰고 2부·3부로 갈 준비를 해달라"는 말을 여러 번 함
- 비싸게 만들어도 안 쓰이는 결과물(옛 소개서처럼)을 가장 경계함

#### 우리 기획안에 대한 현장 반응

- **문의 대응 에이전트 시연**: 상무님이 "ERP랑 비슷해 보인다"고 함. 차별점이 잘 안 보였다는 뜻
- **견적서·맞춤 제안서 자동 생성**: 현실과 잘 안 맞는다는 의견이 꽤 강함
  - 도면 없이 손그림이나 사진만 오는 경우가 많고, 실물이 들어와 봐야 단가가 정해짐
  - 같은 규격이어도 고객마다 요구가 달라서 결국 건별로 처리
  - 고객이 도금을 잘 몰라서 서류를 줘도 어차피 설명해야 하니, 전화나 미팅으로 직접 설명
  - 그래서 공통 소개서까지만 있으면 되고, 맞춤형은 문의가 들어온 뒤에 함
- **잠재고객 발굴**: 신규 고객은 거의 입소문과 소개로 들어옴. 영업이라기보다 납품에 가깝고 영업 인력도 부족. 회의 중 팀원도 "잠재고객 발굴이 지금 필요한 니즈는 아닌 것 같다"고 정리했고, 거산 측이 반박하지 않음
- **보안**: 도면과 현장 노하우 유출을 가장 걱정함. 권한 단계를 나누는 설계는 긍정적으로 봄
- **인력 문제**: 시스템을 들여도 쓸 사람이 한 명뿐이면 그 사람이 나가는 순간 끝이라, 누구나 쉽게 쓸 수 있어야 함

#### 앞으로 협업 방식에 대한 요청

- 궁금한 건 핵심 질문으로 추려서 김복순 부장님과 박 이사님께 주기적으로 메일로 보내달라고 함. 거산이 담당자를 맞춰서 답해줌
- 미팅은 2주 정도 간격, 2회차에는 기술 주제(아연도금)로 하자고 함
- 공정·설비 자료와 시험성적서는 **현장 견학 뒤에** 받는 게 맞다고 함. 인증서는 줄 수 있고, 성적서는 업체명을 빼면 가능할 수도 있음
- 아연도금은 표면처리기능사 자격증 수준으로 미리 공부하고 오라고 함
- 나중에 팀이 이해한 내용을 거산에 다시 설명해서 맞는지 검증받는 단계를 꼭 거치자고 함

**팀 시사점**: 2차로 잡은 잠재고객 추천은 이 회의 기준으로 거산의 우선순위가 아니었음. 거산이 반복해서 원한 건 소개서 자동 생성, 공정도 정리, 불량 대응 가이드 쪽. 9월 이후 거산과 범위를 따로 합의하지 않았다면 2차 기획을 확정하기 전에 이 부분을 맞춰볼 필요가 있음.
