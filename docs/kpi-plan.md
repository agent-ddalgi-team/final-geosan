# 성과(KPI) 후보표 — 10/29 거산 방문에서 정하고, 12/11 발표에서 숫자로 보일 것

PM 세션 초안 2026-10-24(토). 기획서 9.1의 성과 범주(기능 완성·근거성·추천 타당성·업무 효율·사용 편의성·실제 실행)에 맞춰 **발표 때 숫자로 보일 수 있는 것만** 골랐습니다. 숫자 목표는 자료상태메모대로 "G2 전 합의, 미정"이며, 이 표는 그 합의를 위한 재료입니다. 같이 쓰는 문서: 기준선 인터뷰 `docs/visit-interview-20261029.md`, 거산 판정 기록지 `docs/visit-judgment-sheet-20261029.md`, 방문 질문 `docs/visit-questions-20261029.md`.

## 0. 숫자를 적는 규칙 (발표·보고서 공통)

1. **개수로 적는다.** "5곳 중 3곳", "18곳 중 11곳"처럼 분모와 분자를 함께 쓴다. 백분율(%)은 쓰지 않는다. 표본이 작아 %는 과장돼 보인다.
2. **도구 시간은 사람 시간을 포함한다.** "도구로 걸린 시간" = 투입·평가 실행 시간 + **담당자가 결과(목록·근거 상세)를 읽고 접촉 여부를 판단하는 시간**까지. 컴퓨터 처리 시간만 적지 않는다.
3. **기준선은 출처를 붙인다.** 거산이 말로 답한 값은 "(거산 응답 기준, 2026-10-29)"로, 우리가 스톱워치로 잰 값은 "(실측, 날짜)"로 표시한다. 응답값을 실측처럼 쓰지 않는다.
4. **블라인드 판정은 점수·순위를 보여 주기 전에** 받는다. 판정 기록지의 회사 순서는 순위 순이 아니다.
5. 단가·견적·수주 금액은 세지 않는다(CON-23). "접촉 → 회신 → 미팅"까지만 센다.

## 3. 10/29에 정하고 돌아올 것 (체크)

- [ ] 인터뷰 5문항 답(응답 기준으로 기록)
- [ ] 판정 기록지 18곳 채움(블라인드, 점수 보여 주기 전)
- [ ] 상위 5곳 판정 결과(N곳)와 다르게 본 이유
- [ ] 12/11 전까지 실제 접촉해 볼 곳 수와 누가 세어 줄지
- [ ] 거산이 보는 "성공"의 뜻(회신? 미팅? 샘플 의뢰?)
- [ ] 숫자 목표(G2 합의안): 위 결과로 PM이 초안을 만들어 다음 회의에서 정함

## 4. 하지 않을 것

- 수주 금액·단가·견적 성과는 세지 않는다(CON-23).
- 페르소나 v2의 파일럿 목표표(과업 성공률 90% 등)는 **가설**이므로 목표로 못 박지 않고, 10/29 실측·응답으로 바꾼 뒤 쓴다.
- 거산 거래처 목록·내부 이력은 도구에 넣지 않는다. "이미 거래 중" 판정은 종이 기록지에만 남긴다.
