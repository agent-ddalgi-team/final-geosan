## ① 사용 안내 1쪽 — 담당자가 보는 순서대로

프로그램은 화면 세 개로 돌아갑니다. **첫 화면(대시보드) → 영업 후보 목록 → 기업 검토 상세** 순서로 쓰고, 상세 화면 아래에서 기록을 남깁니다.

### 0. 들어가서 제일 먼저 할 일 — 담당자 고르기

- 위쪽 "담당자" 칸에서 **자기 이름을 고릅니다.** 고르지 않으면 보기만 되고, 저장 단추를 누르면 "먼저 담당자를 고르세요"가 나옵니다.
- "보기 전용(대표·상무)"을 고르면 모든 화면을 볼 수 있지만 저장은 되지 않습니다.
- 화면 맨 아래 "내부용 · 고객 제출용 아님" 띠는 늘 보입니다. 이 화면은 거산 안에서만 쓰는 것입니다.

### 1. 첫 화면(대시보드) — 오늘 무엇을 볼지 정하기 ⬜ 그림 1

- **관심 기업 ○곳**: 담당자들이 [관심]으로 담은 회사 수와, 그 가운데 의견 전 / 추가 확인 필요 / 제외가 몇 곳인지 보입니다. 숫자 칸을 누르면 그 회사들만 목록에 걸러서 보입니다.
- **영업 진행**: 관심 기업 가운데 미접촉 / 접촉 중 / 견적·샘플 / 보류 / 완료가 몇 곳인지와 이번 주 일정 건수가 보입니다.
- **일정**: 상세 화면에서 적어 둔 "다음 일정"이 날짜순으로 보이고, 누르면 그 회사로 갑니다.
- **최근 내 기록**: 내가 남긴 최근 기록 10건입니다. 담당자를 바꾸면 그 사람 것으로 바뀝니다.
- **회사 이름 검색**: 이름을 넣고 [검색]을 누르면 그 회사가 목록에 보입니다.

### 2. 영업 후보 목록 — 어느 회사부터 볼지 고르기 ⬜ 그림 2

- 위쪽 메뉴 "영업 후보 목록"을 누릅니다. 처음에는 **공정별 묶음**으로 보입니다(예: "아연도금(전기아연도금) · 9곳"). 공정 선택란에서 공정 하나를 고르면 그 공정의 후보만 순위대로 보입니다. 지역·산업 선택란으로 더 좁힐 수 있습니다.
- 카드 한 장이 회사 하나입니다. 순위, 회사 이름, 분류, 점수("참고 50점 · 3/8"), 영업 단계 꼬리표가 머리에 있고, 아래 세 줄이 **추천 근거 / 검토사항 / 후속 조치**입니다.
- 점수가 흐리고 "거래 확인 전"이 붙은 회사는 아직 거래 여부를 넣지 않은 회사입니다(상세에서 넣습니다, 3-④).
- 카드의 **[관심]** 단추를 누르면 관심 기업에 담깁니다. 팀 전체가 같이 보는 표시입니다. 기록이나 의견이 있는 회사는 관심에서 뺄 수 없습니다.
- 카드의 **담당자 검토 의견** 단추 세 개 — [검토 권고] / [추가 확인 필요] / [검토 대상 제외] — 를 누르면 바로 저장됩니다. 제외는 이유를 꼭 적습니다. 의견을 저장하면 관심이 저절로 켜집니다.
- [자세히 보기]를 누르면 상세로 갑니다.
- AI가 새로 찾아 넣은 회사는 점수가 생기기 전까지 **"점수 전"**으로 목록 **뒤쪽**에 보입니다(공정 적합도 높은 순). 카드에는 AI가 고른 이유 한 줄이 있습니다. 점수는 AI 점수 제안 기능(11월 중)이 들어오면 "확인 전" 흐린 점수로 바뀌고, 담당자가 확인하면 선명해집니다.
- 📅 **엑셀 내려받기**는 2차(11/17 이후)에 넣습니다. 1차에는 없습니다.

### 3. 기업 검토 상세 — 읽고, 확인하고, 기록하기 ⬜ 그림 3·4

**읽는 곳(위에서 아래로)**: 머리(회사 이름·주소·홈페이지·대표번호·회사 소개) → 1. 추천 근거와 후속 조치 → 검토사항 → 2. 고객이 요구하는 것과 거산의 준비 상태 → 3. 공정 적합성 → 4. 근거 자료 → 5. 점수 자세히 보기.

- 머리의 주소 옆 "네이버 지도에서 보기"·"카카오맵에서 보기", "기업 소개 페이지"는 새 창으로 열립니다.
- 머리의 **회사 소개**는 AI가 공개 홈페이지를 읽고 적은 것입니다. 홈페이지 주소가 불확실하면 "홈페이지 확인 필요" 띠가 보이고, 주소 줄 아래 **[맞음] [고치기] [다시 조사]** 단추가 있습니다. [맞음]은 확인만 남기고, [고치기]는 올바른 주소를 넣은 뒤, [다시 조사]는 지금 주소로 AI 조사를 다시 돌립니다(최대 1분, 외부 AI 사용량이 듭니다).
- 머리의 **대표번호**는 공개 홈페이지·공공자료에서 가져온 회사 대표번호입니다. [맞음]을 누르면 확인한 사람과 날짜가 남습니다.

**새로 생긴 입력 4가지(기록 네 칸과 함께 씁니다)**

| 어디 | 무엇을 하나 | 어떻게 |
|---|---|---|
| ① [검토사항 › 체크] | AI가 낸 확인 질문, "자료 못 찾음", "자료 부족" 줄을 확인했으면 표시 | 줄 앞 네모를 누릅니다. 위에 "확인 2 / 5"처럼 진행이 보입니다 |
| ② [검토사항 › 답 적기] | 고객에게 들은 답을 그 질문 아래에 적기 | 질문 줄의 [답 적기]를 누르고 적습니다. 고칠 때는 [답 고치기]. 답은 영업 메모처럼 내부용입니다 |
| ③ [기록 › 영업 단계 "거절"] | 거절로 끝났을 때 이유 남기기 | 단계를 "거절"로 바꾸면 **거절 이유**를 고릅니다: 가격 / 납기 / 기존 거래처 유지 / 수요 없음 / 품질·인증 요건 / 기타(기타만 글로 적음) |
| ④ [머리 › 거래 관계] | 이 회사와 이미 거래가 있는지 넣기 | **[거래 없음] [거래 중] [확인 전으로]** 가운데 하나를 누릅니다. 저장되면 점수가 선명해지고 순위가 다시 맞춰집니다. "거래 중"인 회사는 목록 맨 아래로 갑니다 |

거래 관계는 전달 뒤 거산이 쓰면서 넣기로 한 것입니다(11/3 합의). 처음에는 모두 "확인 전"이라 점수가 흐리게 보이고, ④를 넣을수록 목록이 정확해집니다.

**기록 남기기 네 칸(상세 화면 아래)**

| 칸 | 적는 것 | 알아 둘 것 |
|---|---|---|
| 기록 남기기(접촉·메모) | 종류(전화·방문·메일·메모·자료 조사), 결과(연결됨·부재·거절), 날짜, 내용 | 저장한 기록은 고치거나 지울 수 없습니다. 잘못 넣었으면 메모로 바로잡아 주세요([잘못 입력] 표시는 2차) |
| 담당자 검토 의견 | [검토 권고] / [추가 확인 필요] / [검토 대상 제외] | 목록 카드의 단추와 같은 것입니다 |
| 영업 단계 | 미접촉 · 접촉 · 견적 · 샘플 · 보류 · 성사 · 거절 | 거절이면 위 ③의 이유를 고릅니다 |
| 다음 일정 | 날짜와 할 일 한 줄 | 첫 화면 "일정"에 나옵니다 |

저장한 것은 모두 **활동 이력**에 "누가 언제 무엇을"로 쌓이고, 위의 전체 / 영업 활동 / 사실 / 의견 단추로 골라 볼 수 있습니다.

### 4. 메모와 대표번호는 프로그램 밖으로 나가지 않습니다

- 영업 메모와 검토사항의 답에는 상대 회사 담당자의 전화·이메일을 적어도 됩니다. 거산 담당자가 직접 연락할 때 쓰는 **내부 메모장**입니다.
- 메모·답·대표번호는 외부 AI, 웹 검색, 엑셀, 질문 목록, 저장소 파일 어디에도 내보내지 않습니다. AI 조사는 공개 홈페이지만 읽습니다.
- 메모는 **담당자 전원이 같이 봅니다.** 개인 수첩이 아닙니다.
- 메모에 적은 연락처는 거산이 관리하는 개인정보입니다. 불필요해지면 지워 달라고 운영 담당에게 요청해 주세요(지우는 일은 운영 담당이 합니다).

### 5. 화면에 "가상 사례"·"거산 확인 전" 꼬리표가 보이면

- "가상 사례"는 팀이 시험용으로 만든 회사입니다. 거산의 실제 사양이 아닙니다.
- "거산 확인 전"은 회사소개서에서 옮긴 거산의 역량 값을 아직 거산이 검수하지 않았다는 뜻입니다. 검수가 끝나면 사라집니다.
- "재평가됨"은 거래 관계·새 근거 때문에 점수가 다시 계산됐다는 뜻입니다.

## ② 접속 안내

| 항목 | 내용 |
|---|---|
| 접속 주소 | 화면 주소 하나(Vercel)로 들어갑니다. 서버(Railway)는 화면 뒤에서 돌고 따로 열 일이 없습니다. **주소는 첫 배포(#213) 뒤 직접 알려 드립니다.** |
| 비밀번호 | 공용 비밀번호 하나입니다. 메일·메신저·이 문서에 적지 않고 **직접(전화 또는 대면) 전달**합니다. 처음 열면 비밀번호 화면이 나오고, 넣으면 12시간 동안 다시 묻지 않습니다. 5번 틀리면 30초 뒤에 다시 시도하라는 안내가 나옵니다. |

| 쓰는 기기 | PC 브라우저(크롬·엣지)에서 씁니다. 좁은 화면(휴대폰)에서는 넓은 화면에서 써 달라는 안내만 나옵니다. |
| 안 될 때 | 오류 화면에 "문의 번호"가 보이면 그 번호와 함께 운영 담당에게 알려 주세요. 운영 담당이 누구인지는 #275 1장에서 확인 중(추천: 12/11까지 팀). |

## ③ 백업과 되돌리기 — 운영 담당용 (자세한 것은 `docs/backup-restore-guide.md`)

프로그램의 모든 자료는 파일 하나(`geosan.db`)에 있습니다. **백업은 이 파일을 한 벌 복사해 두는 것**, 되돌리기는 복사해 둔 파일을 제자리에 넣는 것입니다.

### 1. 백업 — 서버를 켜 둔 채로, 주 1회

```
geosan backup --to /data/backups
```

- 결과로 `geosan-<날짜>-<시각>.db` 파일이 생깁니다. 담당자가 쓰는 중이어도 됩니다.
- 새 버전을 올리기 직전, 설정을 한꺼번에 바꾸기 직전에는 꼭 한 번 더 합니다.
- **백업 파일에는 영업 메모와 대표번호가 들어 있습니다.** 거산이 지정한 저장 자리에만 두고, 메일·외부 AI·팀 PC로 보내지 않습니다.

### 2. 되돌리기 — 서버를 멈춘 상태에서만

1. 서버를 멈춥니다(Railway 서비스 잠시 중지). 켜진 채로는 명령이 거부합니다.
2. `geosan restore /data/backups/geosan-<날짜>-<시각>.db` → "계속할까요?"에 `y`. 지금 쓰던 파일은 `geosan-before-restore-…`로 자동 보관됩니다.
3. `geosan init-db`(옛 백업이면 필요한 갱신만 적용).
4. 서버를 다시 켜고, 목록 화면에서 회사 수와 최근 기록이 백업 시점과 맞는지 봅니다.

코드 자체가 문제면 Railway·Vercel의 "이전 배포로 되돌리기"를 누르고, 자료가 문제면 위 순서를 합니다.

### 3. AI 조사가 "사용량 확인 중"으로 막혔을 때

응답을 못 받은 AI 호출이 10분 넘게 미확정으로 남으면 조사 단추가 잠깁니다. 운영 담당이 OpenAI 사용량 화면에서 실제 사용량을 확인해 `geosan transfer-unblock` 명령으로 정리합니다. 순서와 필요한 계정 권한은 `docs/transfer-unblock-guide.md`에 있습니다(OpenAI 조직의 사용량 조회 권한이 있는 계정이 필요합니다).

## ④ 전달 메일 문안 (초안)

> 제목: [거산 영업지원 프로그램] 1차 전달 안내와 접속 방법
>
> 안녕하세요, 최지예입니다.
>
> 거산 영업지원 프로그램 1차를 전달드립니다. 11/15는 마감이 아니라 되는 순서대로 전달하기로 한 날이라, 먼저 쓸 수 있는 것부터 열어 드리고 나머지는 되는 대로 이어서 올립니다.
>
> **지금 쓸 수 있는 것**
> - 첫 화면(관심 기업·영업 진행·일정·최근 기록), 영업 후보 목록(공정·지역·산업별 보기, 관심 담기, 검토 의견), 기업 검토 상세(추천 근거·검토사항·요구와 준비 상태·근거 자료·점수)와 기록 네 칸.
> - 새로 생긴 입력 4가지: 검토사항 체크·답 적기, 거절 이유 선택, 거래 관계 입력. 사용법은 첨부 안내서 ①-3입니다.
> - 거래 관계(거래 없음 / 거래 중)는 쓰시면서 넣어 주시기로 한 대로, 상세 화면 머리의 단추로 넣으시면 됩니다.
>
