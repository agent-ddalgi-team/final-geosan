이 서비스의 핵심 — 쓸수록 거산에 맞게 순위·근거가 맞춰진다

공개 자료로 한 번 뽑은 순위를 보여 주고 끝나는 도구가 아닙니다. 담당자가 기록을 남길수록 그 기록이 순위와 근거에 되돌아와 거산의 영업 방식에 맞춰 가는 영업 비서가 목표입니다. (PM 결정 2026-11-08)

순위를 보고 → 연락하고 기록을 남기면 → 그 기록이 세 갈래로 순위에 돌아옵니다. 1차(지금)는 기록 남기기와 "그때 본 평가 번호" 남기기까지, 세 갈래 되먹임은 2차입니다.

출력이 입력이 되는 고리 세 개

  1. ③·⑤ → ⑥ 사람이 적은 사례 파일과 AI가 뽑은 근거가 같은 모양의 근거·요구·8항목 입력으로 합쳐져 평가에 들어갑니다. AI가 뽑은 것은 "AI 제안·확인 전"으로 구분됩니다.

  3. D8·D9 → ③′ → ④⑤⑥ 공공 자료에서 찾은 회사도 사례 파일로 넣은 회사와 같은 길(홈페이지 찾기 → 근거 뽑기 → 평가)을 탑니다. 사람이 8항목을 적지 않았으므로 "점수 전"입니다.
