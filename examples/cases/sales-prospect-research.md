# 거산 영업 후보 조사: 우선 확인 3곳과 예비 1곳

조사 기준일: 2026-10-23 · 연결 이슈: #20 · PR: #54

## 목적과 판단 기준

거산의 전기아연도금·아노다이징 영업을 위해, 천안·아산·대전·세종·평택·안성·청주에서 먼저 확인할 회사를 고른다. 제품에 도금이 쓰인다는 사실만으로 외주 발주처로 분류하지 않고, 협력업체 생산 또는 후처리 주문·발주 업무의 공개 근거를 우선한다.

**우선 확인 대상은 비링커·성우시스템·금오기술이며, 센아이즈는 예비 후보다. 현재 목표 공정의 외주 발주처로 확정한 회사는 0곳이다.** 세 회사 선정은 연락·확인 순서를 정한 것이며, 현재 발주나 거산 수탁 가능성을 확정한 것이 아니다. 순서는 아래 근거의 구체성과 목표 공정 관련성을 종합한 조사자의 판단이다.

도금·아노다이징 수탁을 주업으로 하는 동종 표면처리 업체를 제외하기 위해 공개 사업 소개를 기준으로 1차 선별했다. 선정 회사의 공개 역할은 제조 중개·가공·장비 제작이며, 거산과의 경쟁 여부는 잠정 판단이다. 자체 표면처리 설비 부재와 사업 중복 여부를 모두 확인한 것은 아니므로 협력 관계를 검토할 때 자체 처리 여부와 사업 중복 여부를 다시 확인한다.

| --- | --- | --- | --- | --- |
| 1 | 비링커 / 천안 직산 공장 | 아노다이징 납품 사례, 파트너 제조망 운영 | 목표 공정과 협력 생산 운영 근거를 함께 볼 수 있음 | 우선 확인 |

## 1. 비링커

### 확인된 근거

- [공식 제조 서비스 안내](https://belinker.co.kr/manufacturing)는 파트너 제조망을 통한 생산과 주문·진행·품질 관리 서비스를 설명하고, 후처리 항목에 아노다이징 Type II·III를 제시한다. 제조를 연결하고 관리하는 업체로 볼 근거이며, 거산과 같은 표면처리 전문 수탁업체라고 단정할 근거는 아니다. 게시일은 확인되지 않았고 열람일은 2026-10-23이다.
- [공식 아노다이징 납품 사례](https://belinker.co.kr/blog/en/quick-turn-cnc-mct-anodized-aluminum-parts)는 알루미늄 부품의 백색 아노다이징과 3일 납품 과정을 소개한다. 게시일은 **2026-07-29**이며, 이 날짜를 실제 발주일로 해석하지 않는다. 회사 자체 사례 소개로, 독립적인 주문서 확인은 아니다.
- [공식 천안 테크센터 이전·확장 안내](https://belinker.co.kr/blog/ko/비링커-매뉴팩처링-천안-테크센터-대지-약-1300평-규모로-확장-65280)는 성환에서 직산으로 공장을 이전했다고 설명한다. 게시일은 **2025-08-09**이며 실제 이전일로 해석하지 않는다. 이 안내를 대상 지역 근거로 사용하되, 공장 소재지가 천안이라는 사실만으로 구매·발주 담당 조직도 천안에 있다고 보지 않는다.

### 미확인 사항과 다음 확인

아노다이징 업체에 비링커가 직접 주문·정산하는지, 가공 협력사가 다시 외주를 주는지는 미확인이다. 신규 표면처리 협력사 모집 여부, 거산의 등록 자격, 현재 물량과 규격, 자체 처리 설비 여부도 미확인이다. 통합 제조 서비스의 영업 영역은 일부 겹칠 수 있다.

우선 질문은 “아노다이징을 직접 구매하는 담당 조직이 있는가, 신규 협력사를 검토하는가”이다. [공식 제조 문의](https://belinker.co.kr/requests/manufacturing)는 접근 가능한 일반 문의 경로이며, 협력사 등록 전용 창구로 확인된 것은 아니다. 문의는 제출하지 않았다.

## 2. 성우시스템

### 확인된 근거

- [고용24 채용 공고](https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do?infoTypeCd=VALIDATION&infoTypeGroup=tb_workinfoworknet&wantedAuthNo=K180612610200003)의 회사는 평택 청북 소재 **주식회사 성우시스템**이다. 동명 회사와 구분해 사용한다.
- 공고는 **2026-10-20 등록**, 2026-11-03 마감 예정이며, 직무에 후처리인 도장·도금의 발주 및 입고관리, 외주임가공 관리를 기재한다. 채용 직무는 외주 운영을 판단하는 근거이며, 특정 거래의 발주서나 현재 주문 잔량을 확인한 자료는 아니다.
- 회사 소개와 직무는 통신장비 제조·가공, 방산·민수 반도체 분야 판금·정밀가공 및 Al·SUS 소재 조달을 설명한다. 공정 수탁 전문업체보다 가공품의 후처리를 발주할 가능성이 있는 제조업체로 우선 확인한다.

### 미확인 사항과 다음 확인

공고의 “도금”이 **전기아연도금인지 아노다이징인지 확인되지 않았다.** Al 소재를 다룬다는 이유로 아노다이징 발주를 추정하지 않는다. 도금의 외주 업체·현재 물량·자체 처리 설비·신규 업체 등록 조건도 미확인이다.

먼저 후처리 발주 품목의 도금 종류를 확인한다. 목표 두 공정에 해당하지 않으면 이번 후보에서 제외하고, 해당하면 소재·치수·품질 기준과 협력사 등록 가능성을 확인한다.

## 3. 금오기술

### 확인된 근거

- [사람인 구매관리 채용 공고](https://www.saramin.co.kr/zf_user/jobs/view?rec_idx=53997693)는 청주 오창 소재 금오기술의 업무로, 사내 가공품 소재 주문·입고관리 및 연마·도금·열처리 등 후처리 주문·납기관리를 설명한다. 외주가공 업체 견적 접수·발주·납기·품질관리도 별도로 명시한다.
- 확인한 게시일은 **2026-05-27**이며 현재 마감된 공고다. 이후에도 같은 발주 업무가 유지되는지 확인되지 않았다. 이 공고를 최신 발주 실적이라고 표현하지 않는다.
- 공개 공고상 기계 제조와 정밀가공품 구매·외주관리 역할이 확인되어, 표면처리 전문 수탁업체로 확정된 곳과 구분해 조사 대상으로 남긴다.

### 미확인 사항과 다음 확인

후처리 “도금”의 종류가 **전기아연도금 또는 아노다이징인지 미확인**이다. 외주가공 발주 직무와 후처리 주문 직무가 함께 있다는 사실이 도금의 특정 외주 계약까지 증명하지는 않는다. 현재 발주 운영, 자체 처리 여부, 신규 협력사 수요도 미확인이다.

먼저 현재 도금 구매 업무가 유지되는지와 실제 발주 공정명을 확인한다. 둘 다 확인되면 소재·제품 치수·물량·검사 조건을 받아 거산의 수탁 가능성을 비교한다. 공식 홈페이지는 이번 확인에서 정상 열람하지 못해 그 내용을 근거로 보충하지 않았다.

## 예비 후보: 센아이즈

### 확인된 근거

- [공식 홈페이지](https://www.seneyes.co.kr/)는 제품 설계·시제품·금형 등의 제작을 협력업체와 수행한다고 설명한다. 대전 대덕 소재 업체이며, 이 안내의 게시일은 미확인, 열람일은 2026-10-23이다. 안내는 일반 제작 협력에 관한 내용이다.
- [공식 블로그 알루미늄 케이스 사례](https://blog.naver.com/seneyes3435/223196794090)는 **2023-08-29** 게시물로, 알루미늄 케이스의 가공과 아노다이징 색상 처리를 소개한다. 해당 아노다이징을 외주로 맡겼다고 명시하지는 않는다.
- [생산 설비 소개](https://blog.naver.com/seneyes3435/222661842847)는 **2022-03-02** 게시물이다. 소개 목록에서 아노다이징 설비를 찾지 못했다는 사실만으로 설비가 없거나 외주라고 판단하지 않는다.

### 미확인 사항과 예비 분류 이유

아노다이징의 직접 수행·외주 여부, 현재 운영 여부, 발주 주체 모두 미확인이다. 일반 협력 생산 안내와 오래된 아노다이징 사례를 연결해 실제 외주를 단정할 수 없어 우선 3곳보다 뒤에 둔다. 우선 질문은 해당 공정의 외주 여부와 최근 반복 생산 유무다.

## 자료의 사용 범위와 조사 완료 기준

이 자료는 **영업 후보 조사 메모**이며 CaseFile 입력 자료가 아니다. 기존 명화금속·스틸앙카·대영프로파일의 PR 추가 JSON 3개를 이 자료로 교체했다. 공정이 미확인인 회사에 임의의 공정 코드를 넣거나 점수·적합 판정을 만들지 않는다. `check-case`·DB 투입·점수 평가 대상으로 사용하지 않는다.

기존 `docs/case-file-guide.md`의 CaseFile 수집 기준은 채용 사이트를 제외한다. 이번 사용자 지시로 조사 범위를 외주 운영 근거로 변경하면서 성우시스템·금오기술의 공개 채용 직무를 **사람이 검토하는 조사 근거에 한해** 사용했다. 기존 수집 허용 기준·약속 파일·자동 수집 설정을 변경하거나 채용 자료를 자동 평가 입력으로 승인한 것은 아니다.

이번 작업의 완료 기준은 3곳과 예비 1곳의 선정 이유, 출처, 근거 날짜, 미확인 사항을 검토할 수 있도록 정리하고 저장소 검사를 통과하는 것이다. 기업 답변·발주 확정·신규 협력사 등록은 후속 영업 확인 사항이므로 조사 PR 완료 조건과 구분한다. 연락처와 담당자 이름은 수록하지 않았다.

후속 확인에서 목표 공정, 외주 운영, 구매 주체 및 현재 수요가 확인된 회사만 발주처로 확정한다. 거산과의 적합성은 추가로 소재·제품 크기·도금 규격·인증 요구·물량·납기를 대조해야 하며, 이번 조사만으로 수탁 가능하다고 결론내리지 않는다.
